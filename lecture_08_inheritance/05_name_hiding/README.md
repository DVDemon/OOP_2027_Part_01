# 05. Сокрытие имён и директива `using`

**Пункт плана:** 5.

## Что показывает пример

* Объявление метода в наследнике скрывает **все** одноимённые перегрузки базы.
* Типичную ловушку: `d.foo(3.14)` молча вызывает `foo(int)`.
* Возврат перегрузок базы через `using Base::foo`.
* Явный вызов перегрузки базы через `Base::foo`.

## Запуск

```bash
./build/05_name_hiding
```

## Плохо → Хорошо

**Плохо** — добавить свою перегрузку и потерять остальные:

```cpp
class Derived : public Base {
public:
    void foo(int x);
    // Base::foo(double) больше не видна: d.foo(3.14) -> foo(int)
};
```

**Хорошо** — «воскресить» перегрузки базы:

```cpp
class Derived : public Base {
public:
    using Base::foo;
    void foo(int x);
};
```

**Почему:** поиск имени в C++ сначала находит имя в наследнике и на этом
останавливается — перегрузки базы в этот набор не попадают. `using`
объединяет наборы, и перегрузка выбирается по аргументам.

## Ключевая мысль

Name hiding — это не перегрузка и не переопределение, а именно сокрытие
имени. Если наследник добавляет метод с существующим именем, почти всегда
нужен `using Base::имя`.
