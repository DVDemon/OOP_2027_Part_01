# 05. Сокрытие имён (name hiding) и директива `using`

**Пункт плана:** 5.

## Что показывает пример

* Объявление функции с тем же именем в наследнике скрывает **все** перегрузки базы.
* `using Base::foo;` возвращает перегрузки базового класса в область видимости.
* Явный вызов перегрузки базы через `d.Base::foo(...)`.

## Запуск

```bash
./build/05_name_hiding
```

## Плохо → Хорошо

**Плохо** — объявить перегрузку и потерять остальные перегрузки базы:

```cpp
class Derived : public Base {
public:
    void foo(int x);   // Base::foo(double) теперь СКРЫТА
};

d.foo(3.14);   // тихо вызовет foo(int): 3.14 -> 3 — потеря данных
```

**Хорошо** — вернуть перегрузки базы директивой `using`:

```cpp
class Derived : public Base {
public:
    using Base::foo;   // все foo из Base снова видимы
    void foo(int x);   // плюс наша перегрузка
};

d.foo(3.14);   // корректно: Base::foo(double)
```

**Почему:** разрешение перегрузки в C++ идёт по имени в ближайшей области видимости,
а не по всем базам сразу. `using` объединяет перегрузки базы и наследника в один набор,
устраняя неожиданные неявные преобразования.
