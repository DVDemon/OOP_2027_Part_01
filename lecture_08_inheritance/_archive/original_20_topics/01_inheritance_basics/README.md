## Что показывает пример

* Базовый класс `Animal` и производный `Dog : public Animal`.
* Отношение «является» (is-a): собака — это животное.
* Доступ наследника к `protected`-членам базового класса.
* Обязательную инициализацию базового класса в списке инициализации.

## Запуск

```bash

```

## Плохо → Хорошо

**Плохо** — дублировать поля и методы в каждом «похожем» классе:

```cpp
class Dog {
    std::string name;   // те же поля, что и у Cat, Bird, ...
    int age;
    void info() const { /* копия кода */ }
};
```

При изменении `info()` придётся править все классы — источник ошибок.

**Хорошо** — вынести общее в базовый класс и наследовать:

```cpp
class Dog : public Animal {     // переиспользуем поля и поведение Animal
    std::string breed;
};
```

**Почему:** наследование убирает дублирование и фиксирует отношение is-a в типах,
поэтому `Dog` можно использовать везде, где ожидается `Animal`.
