# 04. Наследование конструкторов (`using Base::Base`)

**Пункт плана:** 4.

## Что показывает пример

* `using Base::Base;` наследует все конструкторы базового класса.
* Унаследованные конструкторы не инициализируют члены наследника —
  для них нужен default member initializer.
* Собственные конструкторы наследника сосуществуют с унаследованными.

## Запуск

```bash
./build/04_inheriting_constructors
```

## Ограничения

* Конструкторы копирования и перемещения через `using` не наследуются.
* Члены наследника инициализируются только значениями по умолчанию.

## Плохо → Хорошо

**Плохо** — вручную дублировать каждый конструктор базы только ради проброса аргументов:

```cpp
class Derived : public Base {
public:
    Derived(int x) : Base(x) {}
    Derived(int x, double y) : Base(x, y) {}   // шаблонный boilerplate
};
```

При добавлении конструктора в базу легко забыть продублировать его в наследнике.

**Хорошо** — унаследовать конструкторы одной строкой:

```cpp
class Derived : public Base {
public:
    using Base::Base;       // все конструкторы Base доступны автоматически
};
```

**Почему:** меньше повторяющегося кода и нет рассинхронизации при изменении базы.
Главное — не забыть про default member initializers для собственных полей наследника.
