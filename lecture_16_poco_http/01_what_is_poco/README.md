# 01. Что такое POCO

**Пункт плана:** 1 — что такое POCO (история, лицензия, области применения).

## Что показывает раздел

Обзорный материал без кода (сборка не требуется).

**POCO** (POrtable COmponents) — кроссплатформенная C++ библиотека, предоставляющая
сетевые, файловые, XML/JSON и другие компоненты «в стиле стандартной библиотеки».

* **Год создания:** 2004, автор — Gunter Obiltschnig.
* **Лицензия:** Boost Software License 1.0 — можно использовать в коммерческих
  проектах без ограничений и без обязанности раскрывать исходники.
* **Области применения:** IoT, встраиваемые системы, микросервисы, REST API.
* **Философия:** C++ без тяжёлых зависимостей; стабильный API, совместимый с
  C++14/17/20 (собирается и в режиме C++20).
* **Сайт:** <https://pocoproject.org>

## Почему POCO, а не Boost.Beast / cpp-httplib

* Цельный фреймворк: сеть, HTTP, JSON, логирование, потоки — в одной экосистеме.
* Стабильный, давно устоявшийся API.
* Активно применяется в embedded и IoT (например, платформа macchina.io).

## Связь с курсом ООП

POCO — практический пример того, как фреймворк опирается на наследование,
полиморфизм и паттерны (Factory Method, Template Method), которые мы изучали.
Дальнейшие разделы лекции показывают это на HTTP-сервере.
