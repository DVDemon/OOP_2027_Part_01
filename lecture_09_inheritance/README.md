# Лекция 9. Наследование

Примеры к лекции. Покрывают все пункты плана: синтаксис наследования и
модификаторы доступа, порядок конструирования/разрушения, наследование
конструкторов, сокрытие имён, срезку объектов, приватное наследование против
композиции, спецификатор `final` и принцип «предпочитайте композицию».

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Запуск примеров:

```bash
./build/01_inheritance_basics
./build/02_access_modifiers
./build/03_construction_order
./build/04_inheriting_constructors
./build/05_name_hiding
./build/06_object_slicing
./build/07_private_vs_composition
./build/08_final_specifier
./build/09_prefer_composition
./build/10_best_practices
```

## Ключевые идеи лекции

1. **`public`-наследование = отношение is-a.** Только оно сохраняет подстановочность
   наследника вместо базы и обязано проходить тест Лисков (LSP).
2. **Модификатор наследования** меняет уровень доступа к членам базы; `private`-члены
   базы существуют, но напрямую недоступны наследнику.
3. **Порядок строго определён:** конструирование сверху вниз (база → члены → тело),
   разрушение — в обратном порядке.
4. **`using Base::Base`** наследует конструкторы базы, но не инициализирует поля
   наследника; копирующий/перемещающий конструкторы так не наследуются.
5. **Name hiding:** перегрузка в наследнике скрывает все одноимённые перегрузки базы;
   возвращает их директива `using Base::foo;`.
6. **Срезка:** копирование наследника в базовый тип отбрасывает производную часть —
   передавайте полиморфные объекты по ссылке/указателю.
7. **Композиция предпочтительнее наследования:** более слабая связь и гибкость;
   приватное наследование оправдано лишь для доступа к `protected`-членам, переопределения
   виртуальных функций или EBO.
8. **`final`** запрещает наследование/переопределение и помогает компилятору
   девиртуализировать вызовы.
9. **Полиморфной базе нужен виртуальный деструктор**, а переопределениям — `override`.
