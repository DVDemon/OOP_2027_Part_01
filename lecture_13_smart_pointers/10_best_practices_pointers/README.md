# 10. Практические рекомендации и типичные ошибки

**Пункт плана:** 10.

## Что показывает пример

* Правильную передачу умных указателей в функции:
  `shared_ptr` по `const&`, `unique_ptr` по значению (через `std::move`).
* Помещение `unique_ptr` в контейнер через `std::move`.
* Закомментированные типичные ошибки рядом с корректными вариантами.

## Запуск

```bash
./build/10_best_practices_pointers
```

## Рекомендации

* **Предпочитайте `unique_ptr`** — он легче и быстрее; к `shared_ptr` переходите
  только при реальной необходимости разделяемого владения.
* **Всегда используйте `make_unique` / `make_shared`** — безопаснее и эффективнее.
* **Не создавайте два `shared_ptr` из одного сырого указателя** — двойной `delete`.
* **Передавайте `unique_ptr` по значению** при передаче владения.
* **Передавайте `shared_ptr` по `const&`**, если счётчик увеличивать не нужно.
* **Используйте `weak_ptr` для разрыва циклов** (двусвязные списки, графы, observer).

## Типичные ошибки

| Ошибка | Последствие | Как правильно |
|--------|-------------|---------------|
| Два `shared_ptr` из одного `new` | двойное освобождение | один владелец, далее копии `shared_ptr` |
| Цикл из `shared_ptr` | утечка памяти | обратная связь через `weak_ptr` |
| `shared_from_this()` без `shared_ptr` | UB / `bad_weak_ptr` | владеть объектом через `make_shared` |
| `shared_ptr<T> self(this)` в стеке | удаление объекта со стека | `enable_shared_from_this` |
| `push_back(p)` для `unique_ptr` | ошибка компиляции | `push_back(std::move(p))` |

## Плохо → Хорошо

**Плохо** — передача `shared_ptr` по значению ради «только чтения»:

```cpp
void inspect(std::shared_ptr<int> p);   // копия -> лишний инкремент счётчика
```

**Хорошо** — по `const&`, когда владение не нужно:

```cpp
void inspect(const std::shared_ptr<int>& p);   // счётчик не трогаем
```

**Почему:** копирование `shared_ptr` — это атомарное изменение счётчика
ссылок, оно не бесплатно. Если функция лишь читает объект и не сохраняет
указатель, копия не нужна — достаточно `const&` (а ещё лучше — сырой указатель
или ссылку на сам объект, раз владение не передаётся).
