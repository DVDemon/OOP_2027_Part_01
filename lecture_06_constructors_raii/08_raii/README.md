# 07. Идиома RAII

**Пункт плана:** 7 — RAII (Resource Acquisition Is Initialization).

## Что показывает пример

* Класс `ScopedTimer` — RAII-обёртка над «ресурсом» (моментом старта): засекает
  время в конструкторе, печатает длительность в деструкторе.
* Деструктор вызывается автоматически при выходе из функции — как при обычном
  возврате (`measured`), так и при выходе через исключение
  (`measured_with_exception`).
* Копирование/перемещение запрещены: таймер привязан к своей области видимости.

## Файлы

* `timer.h` / `timer.cpp` — RAII-класс `ScopedTimer`.
* `main.cpp` — демонстрация для обычного выхода и для исключения.

## Запуск

```bash
./build/07_raii
```

## Плохо → Хорошо

**Плохо** — захватывать и освобождать ресурс вручную:

```cpp
void measure() {
    auto start = clock_now();   // захват
    do_work();                  // если бросит исключение...
    auto end = clock_now();     // ...сюда мы уже не дойдём
    log(end - start);           // и не залогируем
}
```

**Хорошо** — связать ресурс с временем жизни объекта (RAII):

```cpp
void measure() {
    ScopedTimer t("work");      // захват в конструкторе
    do_work();                  // даже при исключении...
}                               // ...деструктор t гарантированно сработает
```

**Почему:** при ручном управлении любой досрочный выход (`return`, `break`,
исключение) пропускает код освобождения — отсюда утечки и «зависшие» ресурсы.
RAII перекладывает освобождение на деструктор, который вызывается
**автоматически** при любом выходе из области видимости, включая раскрутку
стека. Стандартные RAII-обёртки: `std::unique_ptr`, `std::lock_guard`,
`std::fstream`.
