# 05. `=default`, `=delete` и таблица автогенерации

**Пункт плана:** 5 — `=default`, `=delete`, автогенерация спец-методов.

## Что показывает пример

* `Buffer` запрещает копирование (`= delete`) и реализует перемещение вручную.
* `Pod` явно просит стандартные методы через `= default`.
* Перемещение опустошает источник (`std::exchange`), поэтому `b1.size()`
  становится `0`.

## Запуск

```bash
./build/05_default_delete
```

## Таблица автогенерации специальных методов

| Объявлено пользователем | Default ctor | Copy ctor | Copy assign | Move ctor | Move assign | Dtor |
|-------------------------|:---:|:---:|:---:|:---:|:---:|:---:|
| Ничего                  | да  | да  | да  | да  | да  | да  |
| Любой конструктор       | нет | да  | да  | да  | да  | да  |
| Copy ctor               | нет | --  | да  | нет | нет | да  |
| Copy assign             | да  | да  | --  | нет | нет | да  |
| Move ctor               | нет | del | del | --  | нет | да  |
| Move assign             | да  | del | del | нет | --  | да  |
| Destructor              | да  | да* | да* | нет | нет | --  |

\* — генерируется, но deprecated.

## Плохо → Хорошо

**Плохо** — оставить классу с ручным `new[]` автоматически сгенерированный
копирующий конструктор (поверхностная копия):

```cpp
class Buffer {
    int* data_;
public:
    explicit Buffer(std::size_t n) : data_(new int[n]) {}
    ~Buffer() { delete[] data_; }
    // копирующий конструктор сгенерирован: копирует указатель, не память!
};

Buffer a(4);
Buffer b = a;   // b.data_ == a.data_ -> двойное delete[] -> UB
```

**Хорошо** — явно запретить или корректно реализовать спец-методы:

```cpp
Buffer(const Buffer&) = delete;             // запрет копирования
Buffer& operator=(const Buffer&) = delete;
Buffer(Buffer&&) noexcept;                  // корректное перемещение
```

**Почему:** автогенерированные методы делают почленную (поверхностную) копию.
Для класса, владеющего сырым ресурсом, это приводит к двойному освобождению.
`=delete` явно запрещает опасную операцию (ошибка на этапе компиляции вместо UB
в рантайме), а `=default` документирует намерение использовать стандартную
реализацию.
