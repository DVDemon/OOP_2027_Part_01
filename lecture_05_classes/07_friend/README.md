# 07. Дружественные функции и классы

**Пункт плана:** 7 — `friend`.

## Что показывает пример

* `friend`-функция `dot` получает доступ к `private`-полям `Vector2D`.
* `friend`-оператор `operator<<` — свободная функция (левый операнд `std::ostream&`),
  поэтому методом класса её сделать нельзя; `friend` даёт ей доступ к `private`.
* `friend class VectorSerializer` — весь класс получает доступ к `private` членам.

> **Важно:** `friend` не наследуется и не транзитивен. Дружба — это явное,
> точечное предоставление доступа, а не «дыра» в инкапсуляции.

## Плохо → Хорошо

**Плохо** — чтобы внешняя функция/оператор могли работать с объектом, открыть
поля наружу через `public` (или публичные геттеры на всё подряд):

```cpp
class Vector2D {
public:
    double x, y;  // открыли всё, лишь бы operator<< и dot работали
};
```

**Почему плохо:** публичные поля ломают инкапсуляцию — теперь любой код может
читать и писать `x`, `y` напрямую, инварианты не защищены.

**Хорошо** — оставить поля `private` и точечно открыть доступ только нужным
функциям/классам через `friend`:

```cpp
class Vector2D {
    double x_, y_;  // private
public:
    Vector2D(double x, double y) : x_(x), y_(y) {}
    friend double dot(const Vector2D& a, const Vector2D& b);
    friend std::ostream& operator<<(std::ostream& os, const Vector2D& v);
};
```

**Вывод:** `friend` — инструмент для тесно связанных функций/классов (операторы
ввода-вывода, сериализаторы). Используйте экономно: каждая дружба — это часть
инкапсуляции, которую вы сознательно открываете.
