# 01. `struct` vs `class`

**Пункт плана:** 1 — единственное отличие `struct` от `class`.

## Что показывает пример

* В C++ `struct` и `class` — это одно и то же, кроме **доступа по умолчанию**:
  * `struct` — члены по умолчанию `public`;
  * `class` — члены по умолчанию `private`.
* `struct` можно «закрыть» секцией `private`, а в `class` открыть секцией `public` —
  поведение станет одинаковым.
* Конвенция: `struct` — для простых агрегатов данных (POD), `class` — когда есть
  инварианты и поведение.

## Плохо → Хорошо

**Плохо** — сделать класс с инвариантом через `struct` и открытые поля:

```cpp
struct Counter {
    int value;  // public: любой может записать отрицательное значение в обход inc()
};
Counter c;
c.value = -100;  // инвариант «счётчик только растёт» нарушен
```

**Почему плохо:** открытое поле нельзя проконтролировать — любой код может
привести объект в недопустимое состояние, и компилятор это не заметит.

**Хорошо** — закрыть поле и дать доступ только через метод (в `struct` это
делается явной секцией `private`, что и доказывает: разница лишь в умолчании):

```cpp
struct Counter {
private:
    int value_ = 0;
public:
    void inc() { ++value_; }   // единственный способ изменить состояние
    int get() const { return value_; }
};
```

**Вывод:** выбор `struct`/`class` — это сигнал намерения для читателя, а не
техническое ограничение. Для агрегатов берите `struct`, для типов с инвариантами — `class`.
