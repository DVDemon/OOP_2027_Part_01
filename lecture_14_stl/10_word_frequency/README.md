# 10. Частотный анализ слов: всё вместе

**Блок плана:** 10 — прикладной пример, соединяющий контейнеры, итераторы,
алгоритмы и лямбды.

## Что показывает пример

Полная мини-программа «частота слов в тексте»:

1. **Текст → слова** через `std::istringstream` и `std::istream_iterator` — тот же
   приём работает с `std::ifstream`.
2. **`std::map<std::string, int>`** считает частоты: `++freq[word]` вставляет новый
   ключ со значением 0 и инкрементирует; для существующего — просто инкремент.
3. **Пары → `std::vector`**: `map` отсортирован по ключу, а нужен порядок по
   частоте; вектор строится из итераторов `map` одной строкой.
4. **`std::sort` + лямбда-компаратор**: по убыванию частоты, при равенстве — по
   слову.
5. **Топ-N** — вывод первых N элементов.

## Плохо → Хорошо

**Плохо** — частоты вручную, линейным поиском по накопленному списку:

```cpp
std::vector<std::string> words;
std::vector<int> counts;
for (const auto& w : text) {
    auto it = std::find(words.begin(), words.end(), w);   // O(n)
    if (it == words.end()) { words.push_back(w); counts.push_back(1); }
    else ++counts[it - words.begin()];
}
```

**Почему плохо:** на каждое слово — линейный поиск, итого O(n²) на n уникальных
слов; две параллельные структуры нужно держать согласованными.

**Хорошо** — `map` берёт поиск и уникальность на себя:

```cpp
std::map<std::string, int> freq;
for (const auto& word : text)
    ++freq[word];             // O(log n) на слово
```

**Почему хорошо:** `map` объединяет повторы автоматически, а `operator[]` с
последующим `++` — ровно тот случай, когда вставка по умолчанию уместна. Дальше
работают только алгоритмы: перенос в вектор и `sort` с лямбдой.

## Фрагмент вывода

```
=== 1. Слова из текста ===
apple banana cherry apple banana apple date banana apple elderberry cherry 
всего слов: 11

=== 2. Пары «слово, частота» (map отсортирован по ключу) ===
apple: 4
banana: 3
cherry: 2
date: 1
elderberry: 1

=== 3. Топ-3 самых частых слов ===
apple: 4
banana: 3
cherry: 2
```

Этот приём «таблица в памяти → обработка алгоритмами» лежит в основе
лабораторной №6 (реляционные данные в памяти).
