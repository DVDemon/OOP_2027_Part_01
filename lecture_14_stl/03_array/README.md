# 03. `std::array` — статический массив на стеке

**Блок плана:** 3 — `std::array`.

## Что показывает пример

* **Объект и элементы лежат вместе, в кадре стека.** `sizeof(a) == N * sizeof(T)`,
  адрес `a`, `a.data()` и соседней локальной переменной — рядом; кучи нет.
* **Размер — часть типа.** `std::array<int, 5>` знает свой размер на этапе
  компиляции: `static_assert`, `std::tuple_size_v`, `std::get<1>` — всё
  вычисляется компилятором. `constexpr std::array` доступен в `static_assert`.
* **Value-семантика.** Массив копируется целиком, сравнивается `==`, передаётся в
  функцию по значению или `const&` без «decay» в указатель.
* **Алгоритмы STL** работают так же, как с `vector`: `sort`, `accumulate`,
  `min_element`.
* **`at()` проверяет границы**, `operator[]` — нет.
* **CTAD:** `std::array a{1, 2, 3}` выводит `std::array<int, 3>`.
* **Стек не резиновый:** `std::array<int, 1'000'000>` — это ~4 МБ в кадре стека;
  для больших массивов нужен `vector` (данные в куче).

## Плохо → Хорошо

**Плохо** — C-массив:

```cpp
int a[5] = {5, 3, 8, 1, 4};
void f(int a[]);                      // внутри sizeof(a) == sizeof(int*)
std::cout << (a == b);                // сравниваются указатели, не элементы
```

**Почему плохо:** размер теряется при передаче в функцию, массив не копируется по
значению и не сравнивается поэлементно; `sizeof`-трюк работает только в той же
функции, где объявлен массив.

**Хорошо** — `std::array`:

```cpp
std::array<int, 5> a{5, 3, 8, 1, 4};
std::array<int, 5> b = a;      // полная копия
if (a == b) { /* поэлементное сравнение */ }
```

**Почему хорошо:** размер — часть типа, поэтому функция `template<size_t N>
void f(const std::array<int, N>&)` знает `N`. Массив ведёт себя как обычное
значение, а элементы всё так же лежат на стеке без отдельной аллокации.

## Фрагмент вывода

```
=== 1. array живёт на стеке, кучи нет ===
sizeof(a) = 20 == 5 * sizeof(int) = 20
адрес объекта a   (стек): 0x16af35fb0
адрес a.data()    (стек): 0x16af35fb0
адрес local       (стек): 0x16af35fac

=== 3. Value-семантика: копия, сравнение ===
a[0]=5, b[0]=100 — копия независима
a == b? нет

=== 7. Стек не резиновый ===
sizeof(std::array<int, 1'000'000>) = 4000000 байт (~4 МБ): такой объект на стеке — риск переполнения
```

Адреса зависят от запуска; важно, что `a.data()` лежит в том же кадре стека, что
и локальные переменные, а не в куче.
