# 06. Лямбды: захват и замыкание

**Блок плана:** 6 — лямбда-выражения: список захвата, внутреннее устройство.

## Что показывает пример

* **Синтаксис** `[захват](параметры) { тело }` и лямбда без захвата.
* **Захват по значению `[threshold]`** копирует переменную в поле замыкания:
  последующее изменение исходной переменной на лямбду не влияет.
* **Захват по ссылке `[&calls]`** видит изменения и меняет исходную переменную.
* **`mutable`** разрешает менять состояние замыкания; состояние сохраняется между
  вызовами и копируется вместе с замыканием.
* **Смешанный захват `[=, &b]`:** всё по значению, `b` — по ссылке; инициализация
  в захвате `[n = 0]`.
* **Размер замыкания** равен размеру захваченных полей: 1 байт без захвата,
  `sizeof(int)` с одним `int`.
* **Эквивалентность функтору:** `IsEven` и лямбда дают одинаковый результат в
  `count_if`; `typeid` показывает сгенерированный компилятором безымянный класс.
* **`constexpr`-лямбда**, немедленный вызов `[]{ return 42; }()`, опасность
  dangling-захвата `[&local]`.

## Плохо → Хорошо

**Плохо** — состояние предиката в глобальной переменной:

```cpp
int g_threshold = 5;
bool above_global(int x) { return x > g_threshold; }   // скрытая зависимость
```

**Почему плохо:** глобальная переменная связывает функцию и место вызова, ломает
повторное использование и потокобезопасность; для каждого нового порога нужна
новая функция.

**Хорошо** — лямбда хранит состояние в замыкании:

```cpp
int threshold = 5;
auto above = [threshold](int x) { return x > threshold; };
std::count_if(v.begin(), v.end(), above);
```

**Почему хорошо:** функция и её состояние создаются в одной точке, копируются
вместе с лямбдой и не зависят от глобального состояния. Компилятор превращает
лямбду в класс с полем `threshold` и `operator()`, который инлайнится.

## Фрагмент вывода

```
=== 2. Захват по значению: копия на момент создания ===
threshold изменён на 100, above(6)=1 (копия 5 внутри замыкания)

=== 3. Захват по ссылке: видно изменения ===
counted вызвана 2 раза

=== 4. mutable: состояние замыкания можно менять ===
counter(): 1, 2
copy(): 3 — копия начала с n=2

=== 6. Размер замыкания = размер захваченных полей ===
sizeof(без захвата) = 1
sizeof([threshold]) = 4
sizeof([n=0])       = 4

=== 7. Лямбда и функтор для алгоритма эквивалентны ===
count_if(IsEven{}) = 4
count_if(лямбда)   = 4
имя типа лямбды: Z4mainE3$_0 — компилятор сгенерировал безымянный класс
```

Имя типа лямбды и `sizeof` зависят от компилятора; смысл — в том, что замыкание
это обычный класс с полями-захватами.
