# 08. Алгоритмы STL с лямбдами

**Блок плана:** 8 — стандартные алгоритмы с примерами применения лямбд.

## Что показывает пример

* **Немодифицирующие:** `find_if`, `count_if`, `any_of`, `all_of`, `none_of`,
  `minmax_element`.
* **`for_each`** — действие над каждым элементом, в том числе изменение по ссылке.
* **`transform`** и **`copy_if`** — преобразование и фильтрация в новый контейнер.
* **Идиома erase-remove:** `remove_if` только сдвигает элементы и возвращает новый
  конец; размер меняет последующий `erase`.
* **Сортировки:** `sort` с лямбда-компаратором, `stable_sort` (равные сохраняют
  порядок), `partial_sort` для топ-3.
* **`accumulate`** — сумма, произведение, средний балл по записям.
* **`partition`** — разделить диапазон по предикату, **`iota`** — заполнить
  последовательностью.
* **Прикладная задача:** средний балл, число набравших ≥ 90, гистограмма оценок
  на `std::array<int, 4>` через `count_if`.

## Плохо → Хорошо

**Плохо** — ручной цикл под каждую типовую операцию:

```cpp
long long even = 0;
for (std::size_t i = 0; i < v.size(); ++i)
    if (v[i] % 2 == 0)
        ++even;
```

**Почему плохо:** на каждую задачу — свой цикл с индексом, условием и счётчиком.
Ошибки «на один элемент» и переполнение индекса — частые спутники ручных циклов,
а намерение приходится восстанавливать по телу.

**Хорошо** — алгоритм + лямбда:

```cpp
const auto even = std::count_if(v.begin(), v.end(),
                                [](int x) { return x % 2 == 0; });
```

**Почему хорошо:** имя `count_if` называет операцию, лямбда — только условие.
Алгоритм протестирован, не содержит индексации и работает с любым контейнером с
подходящей категорией итераторов.

## Фрагмент вывода

```
=== 1. Поиск и подсчёт (немодифицирующие) ===
find_if(x > 7): 8
count_if(чётные): 5
any_of(x > 9): 1, all_of(x > 0): 1, none_of(x < 0): 1

=== 4. remove_if + erase: идиома erase-remove ===
size до erase: 10 (remove_if только сдвигает элементы, размер не меняет)
только чётные: 8 4 6 2 10

=== 5. Сортировки ===
stable_sort по score (равные сохраняют порядок): Аня(91) Дина(91) Зоя(91) Глеб(88) ...
partial_sort top-3: Аня(91) Дина(91) Зоя(91)

=== 9. Прикладная задача: оценки студентов ===
набрали >= 90: 3
оценка 2: 2
оценка 3: 1
оценка 4: 2
оценка 5: 3
```

Порядок элементов после `partition` стандартом не фиксируется — в выводе он может
отличаться.
