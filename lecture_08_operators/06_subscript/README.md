# 06. Оператор индексирования `[]` (const / non-const)

**Пункт плана:** 6.

## Что показывает пример

* `Matrix` с синтаксисом `m[i][j]` через прокси-классы `Row`/`ConstRow`.
* Две перегрузки `operator[]`: non-const (возвращает `Row`, разрешает
  запись) и const (возвращает `ConstRow`, только чтение).
* Проверку границ с выбросом `std::out_of_range`.

## Запуск

```bash
./build/06_subscript
```

## Плохо → Хорошо

**Плохо** — только non-const версия `operator[]`:

```cpp
double& operator[](std::size_t i);   // нет const-перегрузки
// void print(const Matrix& m) { ... m[i] ... }  // ОШИБКА компиляции
```

ПОЧЕМУ плохо: через `const Matrix&` (например, параметр функции `print`)
вызвать non-const оператор нельзя. Код, читающий константный объект, не
скомпилируется.

**Хорошо** — пара перегрузок:

```cpp
Row      operator[](std::size_t i);        // запись
ConstRow operator[](std::size_t i) const;  // чтение const-объекта
```

ПОЧЕМУ хорошо: компилятор выбирает версию по константности объекта.
const-версия возвращает ссылку на `const`, что защищает от случайной
записи в константный объект.

> Двойной `[][]` достигается прокси-объектом: первый `[]` возвращает
> `Row`, у которого определён свой `operator[]`.
