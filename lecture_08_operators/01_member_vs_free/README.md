# 01. Метод класса vs свободная функция

**Пункт плана:** 1.

## Что показывает пример

* Какие операторы перегружать нельзя: `::`, `.`, `.*`, `?:`, `sizeof`,
  `typeid`, `alignof`.
* Какие — только как метод класса: `=`, `()`, `[]`, `->`, `->*`,
  операторы преобразования.
* Все остальные (`+`, `-`, `*`, `<<`, `==`, `<`, …) — на выбор: метод
  или свободная функция.
* Когда обязателен выбор свободной функции: если левый операнд должен
  допускать неявное преобразование (например, `2 * frac`).

## Запуск

```bash
./build/01_member_vs_free
```

## Плохо → Хорошо

**Плохо** — реализовать `operator*` только как метод и ожидать, что
`2 * frac` скомпилируется:

```cpp
Fraction operator*(const Fraction& rhs) const;  // только метод
// 2 * frac;  // ОШИБКА: у int нет метода operator*(Fraction)
```

ПОЧЕМУ плохо: для выражения `2 * frac` компилятор ищет
`int::operator*` или свободную функцию. Метод класса `Fraction`
не рассматривается, так как левый операнд — `int`.

**Хорошо** — свободная функция, у которой левый операнд тоже участвует
в разрешении перегрузки и может быть преобразован:

```cpp
friend Fraction operator*(int lhs, const Fraction& rhs);
```

ПОЧЕМУ хорошо: симметрия — и `2 * frac`, и `frac * 2` работают.

> **Правило:** если оператор должен допускать неявное преобразование
> левого операнда — делайте свободную функцию.
