# 02. Арифметические и составные операторы

**Пункт плана:** 2.

## Что показывает пример

* Класс `Vector2D` — сквозная сущность лекции.
* Составные операторы `+=`, `-=`, `*=` (метод, возврат `T&`).
* Бинарные `+`, `-`, `*`, реализованные ЧЕРЕЗ составные.
* Унарный минус `operator-`.

## Плохо → Хорошо

**Плохо** — дублировать логику сложения в `+` и `+=`:

```cpp
Vector2D operator+(const Vector2D& rhs) const {
    return Vector2D(x_ + rhs.x_, y_ + rhs.y_);   // логика #1
}
Vector2D& operator+=(const Vector2D& rhs) {
    x_ += rhs.x_; y_ += rhs.y_; return *this;    // логика #2 — копия!
}
```

ПОЧЕМУ плохо: две копии одной формулы. При изменении модели (например,
добавлении координаты `z`) легко поправить одно место и забыть другое.

**Хорошо** — `+` через `+=`, левый операнд по значению:

```cpp
friend Vector2D operator+(Vector2D lhs, const Vector2D& rhs) {
    lhs += rhs;   // единственная реализация логики — в +=
    return lhs;
}
```

ПОЧЕМУ хорошо: формула сложения живёт в одном месте (`+=`). Приём
«lhs по значению» даёт готовый объект-результат без лишних копий.

> Составной оператор возвращает `T&` (для цепочек `a += b += c`),
> бинарный — `T` по значению (это новый объект).
