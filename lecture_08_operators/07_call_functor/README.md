# 07. Оператор вызова `()` — функторы

**Пункт плана:** 7.

* Использование функторов в алгоритмах STL (`std::transform`,

## Плохо → Хорошо

**Плохо** — обычная функция, которой нужен «внешний» параметр:

```cpp
int g_offset = 10;                  // глобальное состояние
int add(int x) { return x + g_offset; }
std::transform(v.begin(), v.end(), v.begin(), add);
```

ПОЧЕМУ плохо: смещение хранится в глобальной переменной — это не
реентерабельно, мешает многопоточности, два разных смещения одновременно
не задать.

**Хорошо** — функтор инкапсулирует состояние в объекте:

```cpp
class Adder {
    int offset_;
public:
    explicit Adder(int offset) : offset_(offset) {}
    int operator()(int x) const { return x + offset_; }
};
std::transform(v.begin(), v.end(), v.begin(), Adder(10));
```

ПОЧЕМУ хорошо: каждый объект-функтор несёт своё состояние; можно создать
`Adder(10)` и `Adder(-3)` одновременно. Компилятор часто инлайнит
`operator()`, поэтому это ещё и быстрее указателя на функцию.

> Функтор — объект с `operator()`. Лямбда-выражения C++ — это, по сути,
> компилятором сгенерированные функторы.
