# Лекция 8. Перегрузка операторов

Примеры к лекции. Покрывают все пункты плана: правила перегрузки и выбор
между методом и свободной функцией, арифметику и составные операторы,
инкремент/декремент, сравнение и `operator<=>` (C++20), потоковый
ввод/вывод, индексирование, функторы, `operator->` и прокси-объекты,
операторы преобразования типа и пользовательские литералы.

Сквозные сущности: `Vector2D` (арифметика), `Money` (литералы и
канонические формы), `Date` (`<=>`).

## Ключевые идеи лекции

1. **Метод vs свободная функция.** Метод фиксирует левый операнд (`*this`);
   свободная функция допускает неявное преобразование левого операнда
   (`2 * frac`) и обязательна для потоковых `<<`/`>>`.
2. **`+=` → `+`.** Бинарный оператор реализуется через составной: логика
   живёт в одном месте, нет дублирования.
3. **Pre/Post `++`.** Префиксный возвращает `T&`, постфиксный — копию `T`
   и принимает фиктивный `int`. Предпочитайте `++i`.
4. **`operator<=>` (C++20).** Один оператор заменяет шесть; `= default`
   даёт лексикографическое сравнение по полям. При ручном `<=>` оператор
   `==` определяют отдельно.
5. **`operator[]` парный.** Нужны const- и non-const-версии, иначе
   константный объект не прочитать.
6. **Функторы** — объекты с `operator()`; хранят состояние и совместимы с
   алгоритмами STL.
7. **`explicit operator T()`** защищает от опасных неявных преобразований
   (особенно `operator bool`).
8. **Пользовательские литералы** (имя с `_`) повышают выразительность и
   защищают единицы измерения.
