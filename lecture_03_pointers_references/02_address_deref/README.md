# 02. Адрес и разыменование. Арифметика указателей

**Пункт плана:** 2.

## Что показывает пример

* `&` — взятие адреса, `*` — разыменование.
* Изменение значения через указатель.
* Арифметика указателей: `p + n` сдвигает на `n * sizeof(*p)` байт.
* Разность указателей (`std::ptrdiff_t`).

## Запуск

```bash
./build/02_address_deref
```

## Плохо → Хорошо

**Плохо** — выход за границы при арифметике указателей (неопределённое поведение):

```cpp
int arr[5];
int* p = arr;
int v = *(p + 10);   // UB: выход далеко за пределы массива
```

**Хорошо** — арифметика только в пределах массива (и максимум «один за концом» для итерации):

```cpp
int arr[5] = {1, 2, 3, 4, 5};
for (int* p = arr; p != arr + 5; ++p) {   // arr + 5 — допустимая граница
    std::cout << *p << ' ';
}
```

**Почему:** стандарт разрешает арифметику указателей только внутри одного массива и на позицию «один элемент за концом». Любой другой адрес — UB, даже если программа «вроде работает».
