# 03. Указатели и массивы

**Пункт плана:** 3.

## Что показывает пример

* Имя массива в выражениях неявно преобразуется в указатель на первый элемент (array-to-pointer decay).
* Эквивалентность `arr[i]`, `*(arr + i)` и даже `i[arr]`.
* `sizeof` массива против `sizeof` указателя.
* Передача массива в функцию: потеря размера vs шаблон со ссылкой на массив.

## Запуск

```bash
./build/03_pointers_arrays
```

## Плохо → Хорошо

**Плохо** — полагаться на `sizeof` внутри функции, принимающей массив: там уже указатель:

```cpp
void f(int data[]) {              // на самом деле int*
    std::size_t n = sizeof(data); // sizeof указателя (8), а не массива!
}
```

**Хорошо** — передавать размер явно либо ссылку на массив (шаблон), либо контейнер:

```cpp
void f(int* data, std::size_t size);     // размер явно

template <std::size_t N>
void g(int (&data)[N]);                   // размер выводится компилятором
```

**Почему:** при передаче в функцию массив «распадается» в указатель и теряет информацию о длине. Размер нужно сохранять явно — иначе легко выйти за границы.
