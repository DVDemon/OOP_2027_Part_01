# 04. `const`-указатели и указатели на `const`. `nullptr`

**Пункт плана:** 4.

## Что показывает пример

* Четыре комбинации `const` с указателями.
* Мнемоника «читай справа налево».
* `nullptr` и его тип `std::nullptr_t`, однозначность при перегрузке.

| Объявление | Менять значение `*p` | Перенаправить `p` |
|---|---|---|
| `int* p` | да | да |
| `const int* p` | нет | да |
| `int* const p` | да | нет |
| `const int* const p` | нет | нет |

## Запуск

```bash
./build/04_const_pointers_nullptr
```

## Плохо → Хорошо

**Плохо** — использовать `NULL` или `0` для указателей: возможна неоднозначность перегрузки:

```cpp
void f(int);
void f(int*);
f(NULL);   // NULL может быть 0 (int) -> неоднозначность / вызов f(int)
```

**Хорошо** — использовать `nullptr` (имеет тип `std::nullptr_t`):

```cpp
f(nullptr);   // однозначно вызывает f(int*)
```

**Почему:** `nullptr` типобезопасен и не превращается в целое число. Дополнительно: помечайте параметры-указатели `const T*`, если функция не должна менять данные — это и документация, и защита от случайной записи.
