# 06. `const` vs `constexpr`

**Пункт плана:** 12 — `const` vs `constexpr`.

## Что показывает пример

* `const` — неизменяемость, значение может вычисляться в рантайме.
* `constexpr` — значение/функция вычислимы на этапе компиляции.
* `static_assert` и использование `constexpr` как размера `std::array`.

## Запуск

```bash
./build/06_const_constexpr
```

## Отличие

| | `const` | `constexpr` |
|---|---------|-------------|
| Когда вычисляется | можно в рантайме | обязано на этапе компиляции |
| Размер массива на стеке | нельзя | можно |
| В `static_assert` | не всегда | да |

## Плохо → Хорошо

**Плохо** — макрос вместо константы: нет типа, нет области видимости, ломает отладку:

```cpp
#define MAX_SIZE 100     // текстовая подстановка, не уважает namespace/scope
```

**Хорошо** — типизированная константа времени компиляции:

```cpp
constexpr int max_size = 100;   // есть тип, область видимости, виден отладчику
```
