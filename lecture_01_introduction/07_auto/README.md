# 07. Вывод типа `auto`

**Пункт плана:** 10.

## Что показывает пример

* Базовый вывод типа из инициализатора.
* `auto` для длинных типов итераторов.
* `const auto&` и structured bindings в range-based `for`.

## Запуск

```bash
./build/07_auto
```

## Плохо → Хорошо

**Плохо** — выписывать громоздкий тип вручную (легко ошибиться, шумно):

```cpp
std::map<std::string, std::vector<int>>::iterator it = data.begin();
```

**Хорошо** — `auto` выводит тип сам:

```cpp
auto it = data.begin();
```

**Но не злоупотребляйте** — тип должен оставаться очевидным читателю:

```cpp
auto result = compute();   // ПЛОХО: какой тип? приходится искать сигнатуру
int  result = compute();   // ХОРОШО, если тип неочевиден из контекста
```

> `auto` обязателен с инициализатором: `auto a;` — ошибка, тип вывести не из чего.
