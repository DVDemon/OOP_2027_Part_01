# 04. Базовые типы, литералы, `sizeof`

**Пункт плана:** 10 — базовые типы данных, литералы, `sizeof`.

## Что показывает пример

* Размеры базовых целочисленных типов (`sizeof`).
* Типы фиксированного размера из `<cstdint>` (`int8_t`, `int32_t`, `int64_t`).
* Литералы в разных системах счисления и разделитель разрядов `'`.
* Типы с плавающей точкой и научную нотацию.

## Запуск

```bash
./build/04_basic_types
```

## Плохо → Хорошо

**Плохо** — полагаться на конкретный размер `int`/`long` (он платформозависим):

```cpp
long timestamp;   // 4 байта на Windows, 8 на Linux — источник багов
```

**Хорошо** — фиксированный размер, когда он важен:

```cpp
std::int64_t timestamp;   // всегда 64 бита
```

**Подводный камень** — ведущий ноль означает восьмеричную систему:

```cpp
int a = 010;   // это 8, а НЕ 10!
int b = 10;    // это 10
```
