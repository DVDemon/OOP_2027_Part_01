# 01. Первая программа: `main`, `argc`/`argv`

**Пункт плана:** 3 — структура программы, точка входа `main`.

## Что показывает пример

* Минимальную структуру программы на C++.
* Форму `main(int argc, char* argv[])` для чтения аргументов командной строки.
* Смысл кода возврата (`return 0` — успех).

## Запуск

```bash
./build/01_first_program "первый аргумент" второй
```

Ожидаемый вывод:

```
Hello, C++20!
Передано аргументов (включая имя программы): 3
  argv[0] = ./build/01_first_program
  argv[1] = первый аргумент
  argv[2] = второй
```

## Две допустимые формы `main`

```cpp
int main() { /* ... */ }                  // без аргументов
int main(int argc, char* argv[]) { /* */ } // с аргументами командной строки
```

* `argc` — количество аргументов, всегда `>= 1` (`argv[0]` — имя/путь программы).
* `argv` — массив C-строк; гарантируется `argv[argc] == nullptr`.

## Плохо → Хорошо

**Плохо** — забыть `return` в обычной функции (не `main`):

```cpp
int compute() {
    // нет return — неопределённое поведение при использовании результата!
}
```

**Хорошо** — `main` единственная функция, где `return 0;` можно опустить:

```cpp
int main() {
    std::cout << "ok\n";
}   // неявно return 0;
```
