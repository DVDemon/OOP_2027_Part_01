# 08. Пространства имён

**Пункт плана:** 10.

## Что показывает пример

* Объявление и использование `namespace`.
* Полное квалифицированное имя (`math::pi`).
* `using`-объявление (вносит одно имя) vs `using`-директива (вносит все).

## Запуск

```bash
./build/08_namespaces
```

## Плохо → Хорошо

**Плохо** — `using namespace std;` в заголовке: загрязняет глобальное
пространство имён у всех, кто включит заголовок, и провоцирует конфликты:

```cpp
// header.h — ПЛОХО
#pragma once
using namespace std;   // теперь у всех count, distance, swap... могут конфликтовать
```

**Хорошо** — точечные `using`-объявления и квалифицированные имена:

```cpp
using std::cout;   // вносим только нужное
std::cout << math::pi;
```

> В `.cpp` `using namespace` локально допустимо, но в заголовках — никогда.
