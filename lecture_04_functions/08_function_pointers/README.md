# 08. Указатели на функции. `std::function`

**Пункт плана:** 8.

## Что показывает пример

* Указатель на функцию (`using BinaryOp = int(*)(int,int)`): присваивание,
  вызов, передача в `apply`, массив указателей.
* `std::function`: хранит обычную функцию, лямбду и лямбду с захватом; проверка
  на пустоту.

## Запуск

```bash
./build/08_function_pointers
```

## Когда что использовать

| Тип | Достоинства | Недостатки |
|-----|-------------|------------|
| Указатель на функцию | нулевой overhead | не хранит лямбды с захватом |
| `std::function` | универсальный | возможна аллокация в куче, косвенный вызов |
| Шаблонный параметр | нулевой overhead, универсальный | раздувание шаблонного кода |

## Плохо → Хорошо

**Плохо** — пытаться положить лямбду с захватом в указатель на функцию:

```cpp
int factor = 10;
int (*fp)(int) = [factor](int x) { return x * factor; };  // ОШИБКА
```

ПОЧЕМУ плохо: лямбда с захватом — это объект с состоянием (хранит `factor`).
Указатель на функцию хранит только адрес кода и не может удержать состояние,
поэтому такое преобразование невозможно (компилируется лишь лямбда БЕЗ захвата).

**Хорошо** — использовать `std::function` (или шаблонный параметр):

```cpp
int factor = 10;
std::function<int(int)> scaled = [factor](int x) { return x * factor; };  // OK
scaled(5);  // 50
```

ПОЧЕМУ хорошо: `std::function` — это полиморфная обёртка, которая хранит любой
вызываемый объект вместе с его состоянием. За универсальность платим возможной
аллокацией и косвенным вызовом; где нужен ноль overhead и захват — берут
шаблонный параметр `template <class F> void run(F f)`.
