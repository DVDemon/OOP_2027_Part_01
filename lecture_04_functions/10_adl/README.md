# 10. ADL (Argument-Dependent Lookup)

**Пункт плана:** 10.

## Что показывает пример

* ADL находит `geometry::describe(...)` без явного `geometry::`, потому что тип
  аргумента `geometry::Shape` объявлен в `namespace geometry`.
* Одно и то же имя `describe` живёт в двух namespace, и ADL выбирает нужную
  функцию по типу аргумента: `geometry::describe` для `Shape`,
  `physics::describe` для `Unit`.
* У фундаментальных типов (`int`) своего namespace нет — ADL для них не
  работает (см. закомментированную строку в `main`).
* Идиома `using util::describe; describe(x);` — ADL предпочтёт специализированную
  функцию для типа аргумента, иначе сработает запасная обобщённая.

## Запуск

```bash
./build/10_adl
```

## Где ADL критически важен

1. **Операторы** — `std::cout << x` работает потому, что ADL ищет `operator<<`
   в namespace типа `x` (сами операторы в этом примере уже перегрузкой не
   задаются — смотрите примеры по классам).
2. **Идиома `swap`** — пользовательский `swap` находится автоматически:
   `using std::swap; swap(a, b);`.
3. **`begin`/`end`** для range-based `for` — находятся пользовательские версии.

## Плохо → Хорошо

**Плохо** — жёстко звать функцию с квалификацией, отключая ADL:

```cpp
template <typename T>
const char* describe_value(T value) {
    return util::describe(value);  // квалифицированный вызов: ADL выключен,
                                   // всегда запасная обобщённая версия
}
```

ПОЧЕМУ плохо: квалифицированный вызов `util::describe` отключает ADL. Если для
типа есть своя, более подходящая функция (например, `geometry::describe` для
`geometry::Shape`), она не будет вызвана — теряется и точность, и расширяемость:
новый тип уже не сможет «подставить» свою версию.

**Хорошо** — идиома «два шага»: подключить запасную версию и вызвать без
квалификации:

```cpp
template <typename T>
const char* describe_value(T value) {
    using util::describe;   // запасная версия становится кандидатом (fallback)
    return describe(value);  // ADL предпочтёт функцию из namespace типа
}
```

ПОЧЕМУ хорошо: неквалифицированный вызов включает ADL, поэтому для
`geometry::Shape` выбирается `geometry::describe`, а для типов без своей версии
сработает `util::describe` из `using`. Это стандартная идиома обобщённого кода.
