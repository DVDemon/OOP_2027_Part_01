# 02. Передача параметров

**Пункт плана:** 2.

## Что показывает пример

* По значению (`int`) — функция получает копию, оригинал не меняется.
* По ссылке (`int&`) — функция меняет оригинал.
* По указателю (`int*`) — как ссылка, но допускает `nullptr`.
* По `const&` (`const std::string&`) — чтение без копирования.

## Запуск

```bash
./build/02_parameter_passing
```

## Когда что использовать

| Тип параметра | Когда использовать |
|---------------|--------------------|
| `T` (по значению) | дешёвые типы (`int`, `double`, указатель) или когда нужна копия |
| `const T&` | чтение без копирования (строки, вектора, объекты) |
| `T&` | функция должна модифицировать аргумент |
| `T*` | необязательный параметр (может быть `nullptr`) |

## Плохо → Хорошо

**Плохо** — передавать «тяжёлый» объект по значению:

```cpp
void process(std::string data) {   // копируется вся строка при каждом вызове
    std::cout << data;
}
```

ПОЧЕМУ плохо: на каждый вызов создаётся полная копия объекта (выделение памяти,
копирование байтов). Для больших строк/векторов это заметные затраты на ровном
месте — функция ведь только читает данные.

**Хорошо** — передавать по `const&`:

```cpp
void process(const std::string& data) {   // только ссылка, копии нет
    std::cout << data;
}
```

ПОЧЕМУ хорошо: передаётся ссылка (фактически адрес), копирования нет. `const`
гарантирует, что функция не изменит аргумент, и позволяет передавать как
переменные, так и временные значения (`process("literal")`).
