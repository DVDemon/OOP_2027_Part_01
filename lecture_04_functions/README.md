# Лекция 4. Функции: перегрузка, параметры, inline, RVO

Примеры к лекции. Покрывают все пункты плана: объявление vs определение,
способы передачи параметров, перегрузку и алгоритм её разрешения, аргументы
по умолчанию, `inline`/`constexpr`, RVO/NRVO, указатели на функции и
`std::function`, рекурсию и ADL.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Запуск примеров:

```bash
./build/01_declaration_definition
./build/02_parameter_passing
./build/03_overloading
./build/04_overload_resolution
./build/05_default_arguments
./build/06_inline_constexpr
./build/07_rvo_nrvo
./build/08_function_pointers
./build/09_recursion
./build/10_adl
```

## Ключевые идеи лекции

1. **Объявление** сообщает о существовании функции; **определение** содержит тело. ODR требует ровно одно определение нешаблонной функции.
2. **`const T&`** — основной способ передачи «тяжёлых» объектов: без копирования и без модификации; `T*` — для необязательных параметров (`nullptr`).
3. **Перегрузка** различает функции по типам и количеству параметров, но **не** по типу возвращаемого значения.
4. **Разрешение перегрузки**: точное совпадение → promotion → стандартное преобразование → пользовательское преобразование; равенство кандидатов — ошибка (ambiguity).
5. **`inline`** в современном C++ — прежде всего разрешение определить функцию в заголовке без нарушения ODR; **`constexpr`** — вычислимость на этапе компиляции.
6. **RVO/NRVO** устраняют копирование при возврате по значению; с C++17 RVO для prvalue гарантирована. `return std::move(local)` — антипаттерн (запрещает NRVO).
7. **Указатели на функции** и **`std::function`** позволяют передавать поведение как данные.
8. **ADL** ищет функции в пространствах имён аргументов — критически важен для операторов и идиомы `swap`.
