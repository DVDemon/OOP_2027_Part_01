# 09. Рекурсия: прямая, хвостовая, взаимная

**Пункт плана:** 9.

## Что показывает пример

* **Прямая** рекурсия: `factorial` вызывает сам себя.
* **Хвостовая** рекурсия: `factorial_tail` — рекурсивный вызов является
  последней операцией; компилятор с `-O2` может развернуть её в цикл.
* **Взаимная** рекурсия: `is_even` и `is_odd` вызывают друг друга (нужны
  предварительные объявления в `recursion.h`).

## Запуск

```bash
./build/09_recursion
```

## Плохо → Хорошо

**Плохо** — рекурсия без базового случая:

```cpp
long long factorial(int n) {
    return n * factorial(n - 1);   // нет if (n <= 1) — бесконечная рекурсия
}
```

ПОЧЕМУ плохо: без условия остановки вызовы никогда не прекращаются, стек
вызовов растёт до переполнения (stack overflow) и аварийного завершения.

**Хорошо** — обязательный базовый случай, а для глубокой рекурсии —
хвостовая форма или цикл:

```cpp
long long factorial(int n) {
    if (n <= 1) return 1;            // базовый случай
    return n * factorial(n - 1);
}

// Хвостовая форма: компилятор (с -O2) превращает в цикл, стек не растёт.
long long factorial_tail(int n, long long acc = 1) {
    if (n <= 1) return acc;
    return factorial_tail(n - 1, n * acc);
}
```

ПОЧЕМУ хорошо: базовый случай гарантирует завершение. Хвостовая рекурсия
позволяет компилятору переиспользовать кадр стека (tail-call optimization),
поэтому даже большая глубина не приводит к переполнению. Где это критично —
надёжнее переписать в явный цикл.
