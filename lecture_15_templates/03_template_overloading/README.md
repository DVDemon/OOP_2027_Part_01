# 03. Перегрузка шаблонов

**Пункт плана:** 3 — перегрузка.

## Что показывает пример

* Перегрузку шаблонов с разным количеством параметров.
* Перегрузку шаблона и обычной функции.
* Специализацию для vector.
* Приоритет вызова: обычная функция > шаблон.

## Запуск

```bash
./build/03_overloading
```

## Плохо → Хорошо

**Плохо** — одна функция на всё:

```cpp
template <typename T> void print(const T& v);
// Нельзя напечатать два значения
```

**Хорошо** — перегрузка для разных случаев:

```cpp
template <typename T> void print(const T& v);
template <typename T, typename U> void print(const T& a, const U& b);
void print(const std::string& s);  // специальная обработка
```
