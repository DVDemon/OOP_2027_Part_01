# 06. Методы-шаблоны

**Пункт плана:** 8 — методы-шаблоны.

## Что показывает пример

* Метод-шаблон `add<U>`, не зависящий от параметра класса.
* Конвертирующий конструктор-шаблон.
* Присваивание между разными инстанцированиями.

## Запуск

```bash
./build/03_template_methods
```

## Плохо → Хорошо

**Плохо** — только один тип:

```cpp
Value<int> vi(42);
vi.add(Value<int>(10));  // только int
```

**Хорошо** — метод-шаблон для любого типа:

```cpp
Value<int> vi(42);
vi.add(Value<double>(3.14));  // double конвертируется в int
```
