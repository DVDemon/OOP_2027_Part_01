# Лекция 15. Основы шаблонов: функции и классы

Примеры к лекции. Покрывают базовый синтаксис шаблонов функций и классов:
вывод аргументов, перегрузку, нетиповые параметры, методы шаблонного класса и
CTAD. Продвинутые темы (forwarding-ссылки, специализация, SFINAE, variadic,
CRTP) остаются в семестре 2.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Запуск примеров:

```bash
./build/01_function_template_basics
./build/02_template_argument_deduction
./build/03_template_overloading
./build/04_class_template_basics
./build/05_class_template_stack
./build/06_template_methods
```

## Ключевые идеи лекции

1. **Шаблон — схема, а не тип.** Конкретная функция или класс появляются при
   инстанцировании.
2. **Форма параметра управляет выводом:** `T` отбрасывает `const` и ссылку,
   `T&` сохраняет, `const T&` добавляет `const`.
3. **Обычная функция предпочитается шаблону** при равном сопоставлении;
   более специализированный шаблон — более общему.
4. **Нетиповой параметр** (`Array<T, N>`) делает размер частью типа.
5. **Шаблон определяется в заголовке**, если не используется явное
   инстанцирование.
6. **У каждого инстанцирования свои статические члены** и свой код.
7. **CTAD** позволяет опускать аргументы шаблона класса там, где они выводятся
   из конструктора.
8. **`using`** создаёт псевдоним шаблона, а не новый тип.

## Связь с остальным курсом

Шаблоны — основа STL: `std::vector`, `std::map`, `std::sort` и
`std::accumulate` параметризованы типами и функторами. В семестре 2 тема
продолжается: forwarding-ссылки, `std::forward`, специализация, SFINAE,
`type_traits`, variadic-шаблоны и CRTP.
