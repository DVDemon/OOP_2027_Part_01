# 02. Параметры шаблона

**Пункт плана:** 2 — параметры шаблона.

## Что показывает пример

* Несколько параметров шаблона (typename T, typename U).
* Параметры-значения (non-type template parameters).
* Значения по умолчанию для параметров шаблона.

## Запуск

```bash
./build/02_template_params
```

## Плохо → Хорошо

**Плохо** — жёстко заданный размер массива:

```cpp
int arr[10];  // магическое число
```

**Хорошо** — размер как параметр шаблона:

```cpp
template <typename T, int Size>
class StaticArray { /* ... */ };
StaticArray<int, 5> arr;
```
