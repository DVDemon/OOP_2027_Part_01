# 02. Копирующий конструктор и копирующее присваивание

**Пункт плана:** 2 — копирующий конструктор и копирующее присваивание.

## Что показывает пример

* Копирующий конструктор `Buffer(const Buffer&)` выделяет новый буфер и
  копирует содержимое (deep copy).
* Копирующее присваивание `operator=(const Buffer&)` с защитой от
  самоприсваивания и безопасным порядком операций.
* Адреса буферов разные — каждый объект владеет своей памятью.

## Запуск

```bash
./build/02_copy_ctor_assign
```

## Плохо → Хорошо

**Плохо** — наивное присваивание: `delete` до выделения нового буфера:

```cpp
Buffer& operator=(const Buffer& other) {
    if (this == &other) return *this;
    delete[] data_;                       // освободили старое
    data_ = new char[other.size_ + 1];    // <- если new бросит исключение,
    std::strcpy(data_, other.data_);      //    data_ останется висячим (dangling)
    size_ = other.size_;
    return *this;
}
```

**Почему плохо:** если `new` бросит `std::bad_alloc`, объект уже потерял
старые данные, а новых ещё нет — `data_` указывает в никуда. Нарушена
гарантия безопасности исключений.

**Хорошо** — сначала выделить новое, потом освободить старое:

```cpp
Buffer& operator=(const Buffer& other) {
    if (this == &other) return *this;
    char* new_data = new char[other.size_ + 1];  // сначала выделяем
    std::strcpy(new_data, other.data_);
    delete[] data_;                               // и только потом освобождаем
    data_ = new_data;
    size_ = other.size_;
    return *this;
}
```

**Почему хорошо:** если `new` бросит исключение, мы ещё не тронули `*this` —
объект остаётся в прежнем валидном состоянии (сильная гарантия исключений).
Ещё элегантнее эту задачу решает идиома copy-and-swap (см. пример 04).
