# 05. Операторы ввода/вывода (`<<`, `>>`)

**Пункт плана:** 5.

## Что показывает пример

* `operator<<` и `operator>>` как свободные функции (`friend`).
* Возврат ссылки на поток — для цепочек `cout << a << b << '\n'`.
* Чтение объекта из `std::istringstream`.

## Запуск

```bash
./build/05_io_operators
```

## Плохо → Хорошо

**Плохо** — пытаться сделать `operator<<` методом класса:

```cpp
class Complex {
    std::ostream& operator<<(std::ostream& os) const;  // метод
};
// Тогда пришлось бы писать:  c << std::cout;  // левый операнд — c!
```

ПОЧЕМУ плохо: у метода левый операнд — это объект класса (`*this`).
Значит синтаксис стал бы `c << cout`, а не `cout << c`. Изменить класс
`std::ostream`, добавив туда метод для нашего типа, мы не можем.

**Хорошо** — свободная функция, левый операнд `std::ostream&`:

```cpp
friend std::ostream& operator<<(std::ostream& os, const Complex& c) {
    os << c.re_ /* ... */;
    return os;   // возвращаем поток -> цепочка cout << a << b
}
```

ПОЧЕМУ хорошо: естественный синтаксис `cout << c`, поддержка цепочек,
доступ к приватным полям через `friend`.

> `operator<<` принимает объект по `const&` (только читает),
> `operator>>` — по неконстантной ссылке (заполняет объект).
