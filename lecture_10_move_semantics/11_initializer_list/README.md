# 11. Конструктор с std::initializer_list

**Пункт плана:** 11 — конструктор из `std::initializer_list`.

## Что показывает пример

* Конструктор `DynArray(std::initializer_list<int>)` собирает объект из списка
  в фигурных скобках: `DynArray a{10, 20, 30}`.
* `std::initializer_list` даёт только `begin()`/`end()`/`size()`, элементы
  доступны **только на чтение** — их копируют в собственный буфер.
* Различие `{ }` и `( )`: `DynArray{5}` — один элемент `5`, `DynArray(5)` —
  пять нулевых элементов.
* Класс по-прежнему владеет буфером, поэтому правило пяти остаётся в силе —
  конструктор из il лишь дополняет способы создания.

## Запуск

```bash
./build/11_initializer_list
```

## Зачем это нужно

`std::initializer_list<T>` — лёгкий «вид» на временный массив, который
компилятор строит из `{ ... }`. Контейнер получает удобный, читаемый способ
инициализации сразу набором значений — как у `std::vector<int> v{1, 2, 3}`.

## Плохо → Хорошо

**Плохо** — заставлять пользователя наполнять контейнер по одному элементу:

```cpp
DynArray a(3);
a[0] = 10;
a[1] = 20;
a[2] = 30;   // многословно и легко ошибиться с числом элементов
```

**Почему плохо:** ручное заполнение многословно, легко забыть элемент или
выйти за границы; нет возможности выразить «создай из этих значений» одной
строкой.

**Хорошо** — конструктор из `std::initializer_list`:

```cpp
DynArray a{10, 20, 30};   // одна строка, читается как список значений
```

**Почему хорошо:** читаемо, безопасно (размер известен из списка), идиоматично
для C++ — так же инициализируются все стандартные контейнеры.

> **Подвох со скобками:** `DynArray{5}` вызывает конструктор из
> `initializer_list` (один элемент `5`), а `DynArray(5)` — конструктор из
> `size_t` (пять элементов). При наличии обоих конструкторов фигурные скобки
> «предпочитают» initializer_list.

## Связь с темой лекции

Конструктор из `initializer_list` не отменяет правило пяти: класс всё равно
владеет динамическим буфером, поэтому копирующие/перемещающие операции и
деструктор определяются как обычно. Присваивание `c = {7, 8, 9}` работает
через временный объект: `{7, 8, 9}` → временный `DynArray` → move-присваивание.
