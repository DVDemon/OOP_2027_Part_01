# 10. Полная реализация класса String

**Пункт плана:** 10 — полная реализация класса `String`.

## Что показывает пример

* Учебный класс `String` с управлением динамической памятью.
* Полное правило пяти: деструктор, копирующий и перемещающий конструкторы,
  присваивание по значению (copy-and-swap обслуживает copy и move).
* `noexcept`-перемещение → корректная работа в `std::vector`.
* Перегруженные операторы: `+`, `+=`, `[]`, `<<`, `==`, `!=`.

## Архитектурные решения

| Решение | Почему |
|---------|--------|
| `operator=` по значению | один оператор обслуживает copy и move (copy-and-swap) |
| `swap` — `friend`, `noexcept` | основа безопасного присваивания |
| move-операции `noexcept` | `std::vector` перемещает, а не копирует |
| `std::exchange` в move-ctor | забрать значение и обнулить источник одним выражением |
| источник остаётся валидной пустой строкой | можно безопасно переиспользовать после move |

## Плохо → Хорошо

**Плохо** — отдельные операторы для copy- и move-присваивания с ручным
управлением и проверками:

```cpp
String& operator=(const String& o) {
    if (this == &o) return *this;
    delete[] data_;
    data_ = new char[o.capacity_ + 1];   // если new бросит — dangling
    std::strcpy(data_, o.data_);
    /* ...скопировать size_, capacity_... */
    return *this;
}
String& operator=(String&& o) noexcept { /* ...ещё одна реализация... */ }
```

**Почему плохо:** дублирование логики, риск ошибиться с порядком
`delete`/`new`, отдельная проверка самоприсваивания, две функции вместо одной.

**Хорошо** — одно присваивание по значению + `swap`:

```cpp
String& operator=(String other) noexcept {  // параметр создан copy- или move-ctor
    swap(*this, other);                       // обмен полей (noexcept)
    return *this;                             // старые данные уйдут с other
}
```

**Почему хорошо:** строгая гарантия исключений (копия делается до изменения
`*this`), самоприсваивание корректно без проверки, один оператор на оба
случая. Это и есть идиома copy-and-swap из пункта 4, применённая на практике.
