# 04. Базовые алгоритмы STL и лямбды

**Пункты плана:** 5, 6 — алгоритмы `sort`/`count_if`/`accumulate`/`for_each`
и минимальные лямбда-выражения.

## Что показывает пример

* `std::sort` — сортировка диапазона за O(n log n), в том числе по убыванию через
  `rbegin`/`rend` и с лямбда-компаратором.
* `std::count_if` — подсчёт элементов по предикату (лямбда).
* `std::accumulate` — свёртка: сумма, среднее, произведение.
* `std::for_each` — применить действие к каждому элементу (в т.ч. модифицируя).
* Ручной цикл **против** алгоритма STL: намерение кода видно сразу.

## Плохо → Хорошо

**Плохо** — «подсчёт чётных» ручным циклом:

```cpp
long long even = 0;
for (std::size_t i = 0; i < v.size(); ++i)
    if (v[i] % 2 == 0)
        ++even;
```

**Почему плохо:** пять строк кода, которые решают элементарный вопрос «сколько
чётных?». Читателю нужно разобрать индекс, условие, счётчик — и это лишь одна из
множества типовых операций.

**Хорошо** — `std::count_if` с лямбдой:

```cpp
long long even = std::count_if(v.begin(), v.end(),
                               [](int x) { return x % 2 == 0; });
```

**Почему хорошо:** одна строка называет операцию (`count_if` = «посчитай, сколько
подходит»), а предикат в лямбде — только условие. Ошибок индексации и счётчика быть
не может; алгоритм протестирован и гарантированно корректен.
