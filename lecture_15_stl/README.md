# Лекция 15. STL: контейнеры, итераторы, алгоритмы

Примеры к лекции. Покрывают все пункты плана: динамический массив `std::vector`,
ассоциативный массив `std::map` и множество `std::set`, единый способ обхода через
итераторы, базовые алгоритмы (`sort`, `count_if`, `accumulate`, `for_each`) с
минимальными лямбда-выражениями, а также сквозной прикладной пример — частотный
анализ слов, который соединяет все компоненты STL в одной программе.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Запуск примеров:

```bash
./build/01_vector
./build/02_map
./build/03_iterators
./build/04_algorithms
./build/05_word_frequency
```

## Ключевые идеи лекции

1. **STL = контейнеры + итераторы + алгоритмы.** Данные и обработка разделены:
   алгоритм работает с парой итераторов, поэтому один и тот же `sort` сортирует
   любой контейнер.
2. **`std::vector`** — непрерывная память, доступ O(1) по индексу, `push_back`
   амортизированно O(1). `size()` — число элементов, `capacity()` — выделенная
   память; при росте `capacity` перераспределение инвалидирует итераторы.
3. **`std::map`** — красно-чёрное дерево: поиск/вставка/удаление за O(log n).
   `operator[]` при отсутствии ключа **вставляет** значение по умолчанию —
   проверяйте наличие через `find`/`count`.
4. **Итераторы** дают единый способ обхода `[begin, end)` для любого контейнера;
   range-for — синтаксический сахар над итераторным циклом.
5. **Алгоритмы** `sort` (O(n log n)), `count_if`, `accumulate`, `for_each`
   заменяют ручные циклы и делают намерение кода явным.
6. **Лямбды** — минимальный инструмент для предикатов и компараторов; подробно
   — в семестре 2.
7. **Реляционные данные в памяти** (вектор записей, map по ключу, set уникальных
   значений) — база лабораторной №6.
