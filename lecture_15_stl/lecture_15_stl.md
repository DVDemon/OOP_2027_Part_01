## 1. Зачем нужна стандартная библиотека

### Проблема: заново изобретаем велосипед

В C вы каждый раз писали свою реализацию динамического массива: ручное выделение
памяти, контроль размера и вместимости, копирование при росте. В каждом проекте —
свои «массивы на стероидах» со своими багами. То же касается хеш-таблиц, списков,
алгоритмов сортировки и поиска: код копировался из проекта в проект и в каждом
месте был свой.

### Решение: Standard Template Library (STL)

STL — это **библиотека обобщённых алгоритмов и структур данных**, которая с 1994 года
входит в стандарт C++. Она построена вокруг трёх основных компонентов:

| Компонент | Отвечает за | Примеры |
|-----------|-------------|---------|
| **Контейнеры** | Хранение данных | `std::vector`, `std::map`, `std::set`, `std::list` |
| **Итераторы** | Единый способ обхода | `it->begin()`, `++it`, `*it` |
| **Алгоритмы** | Обработку данных | `std::sort`, `std::count_if`, `std::accumulate` |

Ключевая идея — **разделение данных и алгоритмов**: алгоритм работает не с конкретным
контейнером, а с парой итераторов, поэтому один и тот же `std::sort` сортирует и
`std::vector`, и `std::deque`. Код, который раньше писался руками, теперь занимает
одну строку и не содержит ошибок управления памятью.

Преимущества STL:

* **Проверенная, эффективная реализация** — деревья, сортировки, сложность O(n log n) гарантированы стандартом.
* **Универсальность** — контейнер `vector<T>` работает с любым типом `T`, у которого есть операции копирования/перемещения.
* **Единый стиль кода** — итераторы и алгоритмы одинаково работают в любом контейнере.
* **Основа для изучения** — как освоите vector/map и итераторы, так без труда разберётесь в `list`, `unordered_map`, `string_view`, `optional` и т.д.

> Важно: STL — это **не отдельная библиотека для скачивания**, а часть стандартной
> библиотеки C++. Подключается заголовочными файлами (`<vector>`, `<map>`,
> `<algorithm>`, `<numeric>`). Писать свой «динамический массив» в промышленном коде
> больше не нужно.

## 2. `std::vector` — динамический массив
> **Пример:** [01_vector](examples/lecture_15_stl/01_vector)

### Что это

`std::vector<T>` — контейнер, хранящий элементы одного типа `T` **в непрерывной
области памяти**, как обычный массив, но с автоматическим управлением размером.
Заголовок: `<vector>`.

```cpp
#include <vector>

std::vector<int> v;          // пустой вектор
v.push_back(10);             // добавить элемент в конец — O(1) в среднем
v.push_back(20);
v.push_back(30);

// доступ по индексу — как у обычного массива, O(1)
std::cout << v[0] << ' ' << v[1] << ' ' << v[2] << '\n';   // 10 20 30
std::cout << v.size() << '\n';                             // 3
```

### Устройство и рост

Вектор хранит три указателя: на начало буфера, на конец заполненной части
(«размер») и на конец выделенной памяти («вместимость»).

* **`size()`** — сколько элементов **сейчас** в векторе.
* **`capacity()`** — сколько элементов **может** хранить без нового выделения памяти.

Когда `size()` достигает `capacity()`, вектор **перераспределяет** память: выделяет
новый буфер (обычно в ~1.5–2 раза больше), копирует или перемещает туда все элементы
и освобождает старый. Отсюда гарантия сложности `push_back` — **амортизированное
O(1)**: отдельная вставка иногда стоит O(n), но в среднем по последовательности
вставок — константа.

```cpp
std::vector<int> v;
std::cout << v.size() << ' ' << v.capacity() << '\n';   // 0 0
for (int i = 0; i < 10; ++i) {
    v.push_back(i);
    std::cout << v.size() << ' ' << v.capacity() << '\n';
}
```

> Перераспределение **инвалидирует все итераторы и указатели** на элементы старого
> буфера. Поэтому нельзя хранить итератор в вектор и продолжать вставлять элементы.

### `size` vs `capacity`: когда и зачем

* Если заранее известно количество элементов — зарезервируйте память:

```cpp
std::vector<int> v;
v.reserve(1000);              // capacity = 1000, size = 0, без 1000 перераспределений
for (int i = 0; i < 1000; ++i) v.push_back(i);
```

* `shrink_to_fit()` — попросить уменьшить `capacity` до `size` (не гарантировано).

### `push_back` vs `emplace_back`

* `push_back(x)` — копирует (или перемещает) **уже существующий** объект `x`.
* `emplace_back(args...)` — **конструирует** объект прямо внутри вектора из аргументов, без лишней копии.

```cpp
struct Point { int x, y; };

std::vector<Point> pts;
pts.push_back(Point{1, 2});     // создали временный Point, потом скопировали
pts.emplace_back(3, 4);         // сразу собрали Point{3,4} внутри вектора
```

### Сложность основных операций

| Операция | Сложность |
|----------|-----------|
| `operator[]`, `at` | O(1) |
| `push_back` (амортизированно) | O(1) |
| `insert`/`erase` в середину | O(n) — сдвиг элементов |
| `size`, `capacity` | O(1) |

> Вектор хорош, когда элементы читают по индексу и добавляют в конец. Вставка
> в середину — дорого; для таких задач смотрим на другие контейнеры (в семестре 2).

## 3. `std::map` — ассоциативный массив
> **Пример:** [02_map](examples/lecture_15_stl/02_map)

### Что это

`std::map<Key, Value>` — контейнер, хранящий пары «ключ → значение» и
**автоматически поддерживающий порядок по ключу**. Внутри — **красно-чёрное дерево**
(сбалансированное бинарное дерево поиска): вставка, удаление и поиск стоят
**O(log n)**. Заголовок: `<map>`.

```cpp
#include <map>
#include <string>

std::map<std::string, int> ages;
ages["Аня"] = 20;               // вставка через operator[]
ages["Борис"] = 21;

std::cout << ages["Аня"] << '\n';            // 20
```

### Основные операции

```cpp
std::map<std::string, int> m = {{"a", 1}, {"b", 2}};

// find — итератор на пару (key, value) или end(), если ключа нет
auto it = m.find("a");
if (it != m.end())
    std::cout << it->first << '=' << it->second << '\n';   // a=1

// count — 1, если ключ есть, иначе 0 (в map ключи уникальны)
if (m.count("b")) { /* ключ есть */ }

// at — значение по ключу, бросает std::out_of_range, если ключа нет
std::cout << m.at("a") << '\n';
```

> **Важная ловушка `operator[]`:** `m["нет_такого"]` **вставляет** элемент со
> значением по умолчанию, если ключа нет. Если вы хотели только проверить наличие —
> используйте `find` или `count`.

```cpp
std::map<std::string, int> m;
std::cout << m.size() << '\n';            // 0
int x = m["новый"];                       // ключ ВСТАВЛЕН со значением 0
std::cout << m.size() << '\n';            // 1  <-- неожиданно!
```

### Обход map

Итератор map указывает на пару `std::pair<const Key, Value>`: `it->first` — ключ,
`it->second` — значение. Элементы обходятся в порядке возрастания ключей (дерево).

```cpp
for (const auto& [key, value] : m)        // structured binding (C++17)
    std::cout << key << " -> " << value << '\n';
```

### `std::set` — частный случай

`std::set<Key>` — то же красно-чёрное дерево, но хранит **только ключи**
(уникальные). Удобен как «множество»: проверка принадлежности, удаление дубликатов.

```cpp
#include <set>

std::set<int> s = {3, 1, 3, 2, 1};
std::cout << s.size() << '\n';            // 3 — дубликаты отброшены
for (int x : s) std::cout << x << ' ';    // 1 2 3 — по возрастанию
```

### Сложность основных операций

| Операция | `std::vector` | `std::map` |
|----------|--------------|------------|
| Поиск по значению/ключу | O(n) — линейный | **O(log n)** — дерево |
| Вставка | O(1) в конец / O(n) в середину | **O(log n)** |
| Доступ по индексу | O(1) | нет (нет индексов) |

> Правило выбора: нужен **порядок вставки и доступ по индексу** → `vector`;
> нужен **быстрый поиск по ключу и уникальность** → `map`/`set`.

## 4. Концепция итераторов
> **Пример:** [03_iterators](examples/lecture_15_stl/03_iterators)

### Что такое итератор

Итератор — это объект, который умеет **указывать на элемент контейнера** и
**перемещаться по контейнеру**, не раскрывая его внутреннее устройство. Для вектора
итератор ведёт себя как указатель, для map — как «умный указатель» на пару.

Единый интерфейс у всех контейнеров:

| Выражение | Смысл |
|-----------|-------|
| `c.begin()` | итератор на **первый** элемент |
| `c.end()` | итератор на «за последним» элементом (полуоткрытый интервал `[begin, end)`) |
| `*it` | разыменование: доступ к текущему элементу |
| `it->field` | доступ к члену (для map — `it->first`/`it->second`) |
| `++it` | переход к следующему элементу |
| `it == jt`, `it != jt` | сравнение итераторов |

### Классический цикл

```cpp
std::vector<int> v = {5, 3, 8, 1};

for (auto it = v.begin(); it != v.end(); ++it)
    std::cout << *it << ' ';              // 5 3 8 1
```

### range-for — синтаксический сахар

Начиная с C++11 цикл по контейнеру можно писать короче — компилятор сам раскрывает
его в итераторный цикл выше:

```cpp
for (int x : v)               // читаем копии
    std::cout << x << ' ';

for (const auto& x : v)       // читаем по ссылке, без копий — предпочтительно
    std::cout << x << ' ';

for (auto& x : v)             // изменяем элементы на месте
    ++x;
```

### Категории итераторов (обзор)

Итераторы отличаются набором поддерживаемых операций. Основные категории:

| Категория | Умеет | Где используется |
|-----------|-------|------------------|
| `forward_iterator` | обход только вперёд | `std::forward_list`, `std::unordered_map` |
| `bidirectional_iterator` | обход вперёд и назад (`--it`) | `std::map`, `std::set`, `std::list` |
| `random_access_iterator` | произвольный доступ (`it + n`, `it - it`) | `std::vector`, `std::deque`, `std::string` |

Для базовых алгоритмов (`sort`, `count_if`, `for_each`) достаточно прохода вперёд;
`std::sort` требует `random_access_iterator` — поэтому вектор сортируется, а список
пришлось бы сортировать отдельным `std::list::sort`.

> Пока важно понимать принцип, а не запоминать иерархию: **любой контейнер можно
> обойти через `begin`/`end` одним и тем же способом**, и алгоритмы STL это используют.

## 5. Базовые алгоритмы STL
> **Пример:** [04_algorithms](examples/lecture_15_stl/04_algorithms)

Алгоритмы лежат в `<algorithm>` (поиск, сортировка, счёт, обход) и `<numeric>`
(накопление, суммы). Все они принимают **пару итераторов** `[first, last)` и работают
с любым контейнером.

### `std::sort` — сортировка

```cpp
#include <algorithm>
#include <vector>

std::vector<int> v = {5, 3, 8, 1};
std::sort(v.begin(), v.end());              // по возрастанию: 1 3 5 8
std::sort(v.rbegin(), v.rend());            // по убыванию:    8 5 3 1
```

Сложность — O(n log n) в среднем. `rbegin`/`rend` — реверсивные итераторы,
позволяют сортировать «наоборот» без обращения массива.

### `std::count_if` — подсчёт по условию

Принимает пару итераторов и **предикат** (функцию, возвращающую `bool`).

```cpp
std::vector<int> v = {1, 4, 6, 3, 8, 2};
long long even = std::count_if(v.begin(), v.end(),
                               [](int x) { return x % 2 == 0; });
// even == 4  (4, 6, 8, 2)
```

### `std::accumulate` — свёртка

Принимает начальное значение и (опционально) бинарную операцию; по умолчанию — сложение.

```cpp
#include <numeric>

std::vector<int> v = {1, 2, 3, 4};
int sum = std::accumulate(v.begin(), v.end(), 0);        // 10
double avg = double(sum) / v.size();                     // 2.5
int prod = std::accumulate(v.begin(), v.end(), 1,
                           [](int a, int b) { return a * b; });  // 24
```

### `std::for_each` — применить действие к каждому элементу

```cpp
std::vector<int> v = {1, 2, 3};
std::for_each(v.begin(), v.end(), [](int& x) { x *= 2; });
// v == {2, 4, 6}
```

### Другие полезные алгоритмы

| Алгоритм | Что делает |
|----------|-----------|
| `std::find` / `std::find_if` | поиск первого элемента (по условию) |
| `std::min_element` / `std::max_element` | минимум / максимум |
| `std::remove_if` | «выбрасывает» элементы, не удовлетворяющие условию |
| `std::copy` | копирование диапазона |

> **Общий паттерн:** «решить задачу над данными» = выбрать контейнер для хранения +
> подобрать алгоритм из STL вместо ручного цикла. Ручной цикл остаётся только там,
> где логика слишком специфична для готового алгоритма.

## 6. Лямбда-выражения — минимум

Многие алгоритмы требуют настроить поведение: предикат для `count_if`, компаратор
для `sort`, операцию для `accumulate`. Для этого подходят **лямбда-выражения** —
безымянные функции, определяемые прямо в месте вызова.

```cpp
// [захват](параметры) -> возвращаемый тип { тело }
auto is_even = [](int x) { return x % 2 == 0; };
```

Три части синтаксиса:

1. **`[]` — список захвата**: какие внешние переменные доступны внутри лямбды. Пустые `[]` — ничего не захватываем. `[x]` — по значению, `[&x]` — по ссылке, `[=]` — всё по значению, `[&]` — всё по ссылке.
2. **`(параметры)`** — как у обычной функции.
3. **`{тело}`** — то, что лямбда делает.

### Пример с захватом

```cpp
std::vector<int> v = {1, 4, 6, 3, 8, 2};

int threshold = 5;
long long above = std::count_if(v.begin(), v.end(),
                                [threshold](int x) { return x > threshold; });
// above == 2  (6 и 8)
```

### Лямбда как компаратор для `sort`

```cpp
std::vector<std::string> words = {"яблоко", "груша", "слива"};

// сортировка по длине строки
std::sort(words.begin(), words.end(),
          [](const std::string& a, const std::string& b) {
              return a.size() < b.size();
          });
// {"слива", "груша", "яблоко"}
```

> Лямбды здесь — **инструмент**, а не тема лекции: подробно (замыкания, захват,
> функциональные объекты, `std::function`) разбираем в семестре 2. Сейчас достаточно
> уметь написать простой предикат и компаратор.

## 7. Прикладной пример: частотный анализ слов
> **Пример:** [05_word_frequency](examples/lecture_15_stl/05_word_frequency)

Соберём всё вместе: `std::map` для счётчиков, `std::vector` для результата,
`std::sort` и лямбды для сортировки по частоте.

**Задача.** По тексту (списку слов) построить таблицу «слово → сколько раз
встретилось» и вывести топ-N самых частых слов по убыванию частоты.

```cpp
#include <algorithm>
#include <iostream>
#include <map>
#include <string>
#include <vector>

int main() {
    const std::vector<std::string> text = {
        "apple", "banana", "apple", "cherry", "banana", "apple"
    };

    // Шаг 1. Считаем частоты: map хранит слово -> число вставок за O(log n)
    std::map<std::string, int> freq;
    for (const auto& word : text)
        ++freq[word];                      // ловушка operator[] здесь — наше преимущество

    // Шаг 2. Переносим пары в вектор, чтобы можно было сортировать
    // (map отсортирован по КЛЮЧУ, а нам нужна сортировка по ЗНАЧЕНИЮ-частоте)
    std::vector<std::pair<std::string, int>> items(freq.begin(), freq.end());

    // Шаг 3. Сортируем по убыванию частоты (при равенстве — по слову)
    std::sort(items.begin(), items.end(),
              [](const auto& a, const auto& b) {
                  if (a.second != b.second) return a.second > b.second;
                  return a.first < b.first;
              });

    // Шаг 4. Выводим топ-2
    const int top = 2;
    for (int i = 0; i < top && i < static_cast<int>(items.size()); ++i)
        std::cout << items[i].first << ": " << items[i].second << '\n';
}
```

```
apple: 3
banana: 2
```

Разбор по шагам:

* **Шаг 1** — `map` даёт O(n log n) на всё построение частот и автоматически избавляет от «двойного счёта» (каждое слово — единственный ключ).
* **Шаг 2** — вектор из пар: итераторы map позволяют построить вектор одной строкой.
* **Шаг 3** — `std::sort` + лямбда-компаратор решают сортировку по частоте, хотя самих данных не «знают» ничего.
* **Шаг 4** — вывод топ-N.

Этот пример — миниатюра настоящей программы: «взять данные → посчитать → отсортировать
→ вывести». Тот же приём лежит в основе лабораторной №6 (реляционные данные в памяти).

## 8. Что углубляем в семестре 2

STL не заканчивается на пяти алгоритмах. В семестре 2:

* **Контейнеры:** `std::list`, `std::deque`, `std::stack`, `std::queue`, `std::unordered_map` (хеш-таблицы, O(1) в среднем), `std::multimap`, `std::multiset`, `std::string_view`.
* **Итераторы:** полная иерархия категорий, `std::back_inserter`, пользовательские итераторы, итераторы как диапазоны.
* **Алгоритмы:** более 100 в `<algorithm>`: `std::copy_if`, `std::transform`, `std::remove_if`, `std::unique`, `std::partition`, `std::lower_bound`, `std::find_if`, модифицирующие и немодифицирующие.
* **Лямбды и функциональные объекты:** захват, изменяемые лямбды, `std::function`, `std::bind`, стандартные функторы (`std::greater<>`).
* **`std::optional`, `std::variant`, `std::tuple`** — типы-обёртки для «может отсутствовать», «один из», «кортеж».
* **Умные указатели** (`std::unique_ptr`, `std::shared_ptr`) и RAII.

Материалы семестра 1 дают базу, на которую всё это ложится без переучивания:
тот же единый интерфейс итераторов и алгоритмов.

---

## Ключевые концепции

- **STL = контейнеры + итераторы + алгоритмы**; разделение данных и обработки.
- **`std::vector`** — непрерывная память, доступ O(1) по индексу, `push_back` амортизированно O(1); `size` ≠ `capacity`.
- **`std::map`** — красно-чёрное дерево, O(log n) на поиск/вставку; `[]` вставляет ключ по умолчанию, `find`/`count` — только проверяют.
- **`std::set`** — множество уникальных ключей (частный случай map).
- **Итераторы** — `begin`/`end`, полуоткрытый интервал `[begin, end)`, единый обход любого контейнера; range-for — синтаксический сахар.
- **Алгоритмы** — `sort`, `count_if`, `accumulate`, `for_each` работают с парой итераторов и с любым контейнером.
- **Лямбды** — безымянные функции для предикатов и компараторов.

## Типичные ошибки

1. **Путать `size()` и `capacity()`** — `size` — это сколько элементов реально лежит в векторе, а не сколько памяти выделено.
2. **`operator[]` map для проверки наличия ключа** — случайно вставляет пустой элемент. Проверяйте через `find`/`count`.
3. **Хранить итератор вектора через перераспределение** — после `push_back`, преодолевшего `capacity`, старые итераторы инвалидируются.
4. **`for (int x : v)` для больших объектов** — копирует каждый элемент; используйте `const auto&`.
5. **Вставка в середину вектора по одному элементу** — O(n) на каждую вставку; подумайте, нужен ли другой контейнер или другой алгоритм.

## Практическое задание

**Анализ результатов тестирования студентов.** Дан список оценок:

```cpp
const std::vector<int> scores = {78, 91, 55, 88, 91, 45, 66, 91, 78, 88};
```

1. Выведите средний балл через `std::accumulate`.
2. Через `count_if` посчитайте: сколько студентов набрали ≥ 90; сколько < 60.
3. Напишите функцию «оценка по 5-балльной шкале» (≥ 90 → «5», 75–89 → «4», 60–74 → «3», иначе «2») и через `std::map<std::string, int>` посчитайте, сколько студентов получили каждую оценку.
4. Отсортируйте оценки по убыванию через `std::sort` и выведите топ-3.

Убедитесь, что ни один результат не посчитан ручным циклом — используйте алгоритмы
STL и лямбды.
