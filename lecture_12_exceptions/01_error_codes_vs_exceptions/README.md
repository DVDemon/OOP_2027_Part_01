# 01. Коды ошибок vs исключения

**Пункт плана:** 1 — коды ошибок vs исключения.

## Что показывает пример

* Возврат ошибки через код возврата и выходной параметр.
* Сообщение об ошибке через `throw`.
* Почему код возврата легко «потерять», а исключение — нет.

## Запуск

```bash
./build/01_error_codes_vs_exceptions
```

## Плохо → Хорошо

**Плохо** — код возврата можно молча проигнорировать, а сигнатура «загрязнена» выходным параметром:

```cpp
int out = 0;
parse_positive("xyz", out);   // забыли проверить статус
use(out);                     // out содержит мусор — ошибка потерялась
```

ПОЧЕМУ плохо: компилятор не заставляет проверять код возврата; результат и
признак ошибки разнесены; из конструктора код возврата вернуть нельзя вовсе.

**Хорошо** — исключение нельзя проигнорировать незаметно:

```cpp
int value = parse_positive_ex("xyz");  // бросит — управление сюда не вернётся
use(value);                            // выполнится только при успехе
```

ПОЧЕМУ хорошо: при ошибке выполнение не продолжается с «мусором»; полезное
значение возвращается напрямую; работает и из конструктора.
