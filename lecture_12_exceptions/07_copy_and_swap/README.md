# 07. Copy-and-swap для строгой гарантии

**Пункт плана:** 7 — copy-and-swap для строгой гарантии.

## Что показывает пример

* Класс `Buffer` — владелец динамического массива.
* `operator=`, принимающий параметр **по значению**, и `swap` с `noexcept`.
* Один оператор присваивания обслуживает и копирование, и перемещение.

## Сборка и запуск

```bash
cmake -S .. -B ../build       # из папки лекции
cmake --build ../build
./../build/07_copy_and_swap
```

Цели: `07_copy_and_swap` — демонстрация в консоли.

## Плохо → Хорошо

**Плохо** — «классический» `operator=`, который сначала освобождает ресурс:

```cpp
Buffer& operator=(const Buffer& other) {
    if (this == &other) return *this;
    delete[] data_;                       // (1) уничтожили старые данные
    size_ = other.size_;
    data_ = new int[size_];               // (2) а если new бросит здесь?
    std::copy(other.data_, other.data_ + size_, data_);
    return *this;
}
```

ПОЧЕМУ плохо: если `new` на шаге (2) бросит `std::bad_alloc`, старые данные
уже удалены (1), а `data_` указывает в никуда — объект разрушен. Это лишь
базовая гарантия (а то и хуже), плюс нужна ручная проверка самоприсваивания.

**Хорошо** — copy-and-swap: все «опасные» действия над копией, фиксация через `swap`:

```cpp
Buffer& operator=(Buffer other) noexcept {  // копия создаётся ДО тела
    swap(*this, other);                     // swap не бросает
    return *this;
}                                           // old-данные уходят с other
```

ПОЧЕМУ хорошо: если копирование параметра бросит — мы не вошли в тело,
`*this` нетронут (строгая гарантия). `swap` — `noexcept`, поэтому фиксация
безопасна. Бонусы: самоприсваивание корректно автоматически, перемещение
обслуживается тем же оператором.
