# 04. Раскрутка стека (stack unwinding)

**Пункт плана:** 4 — раскрутка стека.

## Что показывает пример

* Что происходит при выбросе исключения сквозь несколько функций.
* Разрушение локальных объектов в обратном порядке создания.
* Поиск ближайшего подходящего `catch`.

## Запуск

```bash
./build/04_stack_unwinding
```

Ожидаемый вывод: объекты `L1`, `L2`, `L3` создаются по порядку, а при выбросе
разрушаются в обратном (`L3`, `L2`, `L1`), после чего исключение ловится в `main`.

## Плохо → Хорошо

**Плохо** — управлять ресурсом «вручную» в обход раскрутки стека:

```cpp
void f() {
    Resource* r = acquire();
    risky();          // если бросит — release() ниже не выполнится
    release(r);       // утечка при исключении
}
```

ПОЧЕМУ плохо: при раскрутке стека разрушаются только автоматические объекты;
«сырой» указатель не имеет деструктора, поэтому `release()` пропускается.

**Хорошо** — обернуть ресурс в объект с деструктором (RAII):

```cpp
void f() {
    Resource r;       // деструктор вызовется при раскрутке стека
    risky();          // даже если бросит — r освободится автоматически
}
```

ПОЧЕМУ хорошо: раскрутка стека гарантированно вызывает деструкторы локальных
объектов — именно на этом держится безопасность исключений (см. пример 06).
