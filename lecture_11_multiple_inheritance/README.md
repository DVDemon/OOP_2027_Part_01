# Лекция 11. Множественное и виртуальное наследование

Примеры к лекции. Покрывают все пункты плана: синтаксис множественного
наследования, проблему ромба, виртуальное наследование и ответственность
наиболее производного класса, расположение объекта в памяти, корректировку
указателей, примеси (CRTP), альтернативы (композиция и чистые интерфейсы),
а также практические рекомендации.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Запуск примеров:

```bash
./build/01_basic_syntax
./build/02_diamond_problem
./build/03_virtual_inheritance
./build/04_most_derived_ctor
./build/05_object_layout
./build/06_pointer_adjustment
./build/07_mixins_demo
./build/08_alternatives
./build/09_when_justified
./build/10_recommendations
```

## Ключевые идеи лекции

1. **Множественное наследование** — класс может иметь несколько прямых баз; порядок конструирования задаётся списком наследования (слева направо), а не списком инициализации.
2. **Проблема ромба** — при общем предке без `virtual` в объекте оказываются **две** копии базы: дублирование данных и неоднозначность имён.
3. **Виртуальное наследование** (`virtual public`) гарантирует **единственный** общий подобъект базы.
4. **Most-derived класс** отвечает за вызов конструктора виртуальной базы; вызовы из промежуточных классов игнорируются.
5. **Расположение в памяти**: без `virtual` базы лежат подряд; с `virtual` промежуточные классы хранят `vbptr`, а общая база размещается отдельно.
6. **Корректировка указателей** — приведение к «второй» базе смещает значение указателя; используйте `static_cast`/`dynamic_cast`, **никогда** `reinterpret_cast`.
7. **CRTP-примеси** — безопасная и эффективная (без рантайм-затрат) альтернатива классическому MI.
8. **Композиция и чистые интерфейсы** — предпочтительные альтернативы наследованию от «толстых» классов с данными.
