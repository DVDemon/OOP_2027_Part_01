# 07. LSP — принцип подстановки Лисков

**Пункт плана:** 7 — LSP (контракты и инварианты).

> «Если S является подтипом T, то объекты типа T могут быть заменены объектами
> типа S без нарушения корректности программы».

## Что показывает пример

Классический контрпример `Square : public Rectangle` и его решение через
разделение иерархии. Файлы:

* `shapes.h` — неизменяемые `Rectangle` и `Square` как независимые подтипы
  общей абстракции `Shape`;
* `main.cpp` — корректная подстановка через `Shape::area()`.

## Сборка и запуск

```bash
cmake -S .. -B ../build       # из папки лекции
cmake --build ../build
./../build/07_lsp
```

Цели: `07_lsp` — демонстрация в консоли.

## Плохо → Хорошо

**Плохо** — `Square` наследует `Rectangle` с мутирующими сеттерами:

```cpp
class Square : public Rectangle {
public:
    void set_width(double w)  override { width_ = height_ = w; } // !!
    void set_height(double h) override { width_ = height_ = h; } // !!
};

void test(Rectangle& r) {        // код написан под Rectangle
    r.set_width(5);
    r.set_height(4);
    assert(r.area() == 20);      // для Square area() == 16 -> провал
}
```

**Почему плохо:** клиент, рассчитывающий на независимость ширины и высоты
`Rectangle`, ломается, когда вместо него подставлен `Square`. Нарушены
постусловия базового типа — это и есть нарушение LSP.

**Хорошо** — раздельные неизменяемые подтипы:

```cpp
class Shape    { public: virtual double area() const = 0; /* ... */ };
class Rectangle : public Shape { /* w_, h_ в конструкторе */ };
class Square    : public Shape { /* side_ в конструкторе */ };
```

**Почему хорошо:** нет мутирующих сеттеров — нет возможности нарушить чужие
инварианты. Любой `Shape` корректно подставляется в клиентский код.

## Контракты LSP

* **Предусловия** подтипа не могут быть сильнее, чем у базового типа.
* **Постусловия** подтипа не могут быть слабее.
* **Инварианты** базового типа должны сохраняться.

LSP — фундамент OCP: полиморфное расширение работает только тогда, когда
подтипы честно соблюдают контракт базового типа.
