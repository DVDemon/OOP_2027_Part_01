# 08. Условные конструкции: `if`, init-`if`, `switch`

**Пункт плана:** 8 — условные конструкции `if` (включая C++17 init-if) и `switch`.

## Что показывает пример

* Цепочку `if / else if / else`.
* `if` с инициализатором (C++17): `if (auto it = ...; cond)` ограничивает область видимости.
* `switch` по `enum class`.
* Намеренный `fall-through` с атрибутом `[[fallthrough]]` и несколько `case` подряд.
* `switch` с инициализатором (C++17).

## Запуск

```bash
./build/08_conditionals
```

## Плохо → Хорошо

**Плохо** — вспомогательная переменная «утекает» в окружающую область:

```cpp
auto it = grades.find(name);
if (it != grades.end()) { use(it); }
// it всё ещё видна здесь, хотя больше не нужна — риск случайного использования
```

**Хорошо** — init-if ограничивает время жизни:

```cpp
if (auto it = grades.find(name); it != grades.end()) { use(it); }
// it недоступна за пределами if/else
```

**Плохо** — случайно забытый `break`:

```cpp
switch (x) {
    case 1: foo();   // забыли break — молча проваливаемся в case 2!
    case 2: bar(); break;
}
```

**Хорошо** — ставить `break`, а намеренное проваливание помечать атрибутом:

```cpp
switch (x) {
    case 1: foo(); [[fallthrough]];  // намеренно: компилятор не предупреждает
    case 2: bar(); break;
}
```

> **Почему:** `-Wall`/`-Wextra` предупреждают о неявном проваливании. Атрибут
> `[[fallthrough]]` (C++17) документирует намерение и убирает предупреждение.
