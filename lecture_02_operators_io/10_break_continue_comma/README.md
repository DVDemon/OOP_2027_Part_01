# 10. `break`, `continue`, оператор «запятая»

**Пункт плана:** 10 — `break`, `continue`, оператор «запятая».

## Что показывает пример

* `break` — досрочный выход из цикла.
* `continue` — переход к следующей итерации.
* Выход из вложенных циклов: `break` покидает только внутренний — решаем флагом.
* Оператор «запятая»: вычисляет операнды слева направо, возвращает правый;
  уместен в секции `for`.

## Запуск

```bash
./build/10_break_continue_comma
```

## Плохо → Хорошо

**Плохо** — надеяться, что `break` выйдет сразу из всех вложенных циклов:

```cpp
for (...) {
    for (...) {
        if (found) break;   // выходит ТОЛЬКО из внутреннего цикла
    }
}
```

**Хорошо** — флаг в условии внешнего цикла (или вынести поиск в функцию с `return`):

```cpp
bool found = false;
for (int i = 0; i < n && !found; ++i) {
    for (int j = 0; j < m; ++j) {
        if (cond) { found = true; break; }
    }
}
```

**Плохо** — оператор «запятая» в обычных выражениях (легко спутать с разделителем):

```cpp
int x = (compute_a(), compute_b());   // x == compute_b(); результат a отброшен
```

**Хорошо** — «запятая» только там, где она привычна, — в `for`:

```cpp
for (int i = 0, j = n; i < j; ++i, --j) { ... }
```

> **Почему:** запятая-оператор гарантирует порядок вычисления слева направо и
> отбрасывает все результаты, кроме последнего. Вне `for` это почти всегда
> ухудшает читаемость, поэтому применяется редко.
