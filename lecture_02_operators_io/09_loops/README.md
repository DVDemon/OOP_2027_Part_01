# 09. Циклы: `for`, range-based `for`, `while`, `do-while`

**Пункт плана:** 9 — циклы `for`, range-based `for`, `while`, `do-while`.

## Что показывает пример

* Классический `for`, в том числе с несколькими переменными (оператор «запятая»).
* Range-based `for`: по значению, по `const auto&`, по `auto&`.
* `while` (проверка до тела) и `do-while` (тело хотя бы один раз).
* Вложенные циклы на примере таблицы умножения.

## Плохо → Хорошо

**Плохо** — индексный цикл и копирование элементов в range-for:

```cpp
for (std::size_t i = 0; i < names.size(); ++i) { use(names[i]); }  // шумно, легко ошибиться
for (auto name : names) { read(name); }                            // копия каждой строки
```

**Хорошо** — range-based for с `const auto&`:

```cpp
for (const auto& name : names) { read(name); }   // без копий, без изменения
for (auto& name : names) { name += "!"; }        // ссылка, когда нужно менять
```

**Плохо** — `while`, когда тело обязано выполниться хотя бы раз:

```cpp
while (need_input()) { ask(); }   // если условие сразу ложно, ask() не вызовется
```

**Хорошо** — `do-while`, если первая итерация обязательна:

```cpp
do { ask(); } while (need_input());
```

> **Почему:** `while` проверяет условие ПЕРЕД телом, `do-while` — ПОСЛЕ. Для
> «спросить хотя бы один раз, потом повторять при необходимости» естественен
> `do-while`. Range-based for с `const auto&` — идиома обхода контейнера без копий.
