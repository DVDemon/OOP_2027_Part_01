# 03. Логические операторы и операторы сравнения

**Пункт плана:** 3 — логические операторы (`&& || !`) и сравнения (`== != < <= > >=`).

## Что показывает пример

* Логические операторы и операторы сравнения над `bool` и `int`.
* **Short-circuit evaluation**: правый операнд `&&`/`||` может не вычисляться
  (демонстрируется через функцию с печатью побочного эффекта).
* Идиому безопасного разыменования указателя `ptr != nullptr && *ptr > 0`.
* Ловушку `=` вместо `==`.

## Запуск

```bash
./build/03_logical_comparison
```

## Плохо → Хорошо

**Плохо** — проверять указатель и разыменовывать в неправильном порядке:

```cpp
if (*ptr > 0 && ptr != nullptr) { ... }   // *ptr вычисляется ДО проверки -> UB
```

**Хорошо** — сначала проверка, затем разыменование (порядок важен из-за short-circuit):

```cpp
if (ptr != nullptr && *ptr > 0) { ... }
```

**Плохо** — присваивание в условии:

```cpp
if (n = 0) { ... }   // n стал 0, условие всегда false; обычно опечатка
```

**Хорошо** — сравнение:

```cpp
if (n == 0) { ... }
```

> **Почему:** `&&` и `||` гарантируют порядок вычисления слева направо и
> прекращают вычисление, как только результат известен. Это позволяет
> безопасно объединять проверку и использование в одном условии.
