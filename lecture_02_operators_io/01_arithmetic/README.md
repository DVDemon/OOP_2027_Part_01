# 01. Арифметические операторы

**Пункт плана:** 1 — арифметические операторы (`+ - * / %`).

## Что показывает пример

* Целочисленное деление с усечением к нулю и остаток `%`.
* Почему `17 / 5 == 3`, а не `3.4`, и как получить дробный результат.
* Поведение `%` для отрицательных чисел и «математический» модуль `floor_mod`.
* Защиту от деления на ноль через `std::optional` (UB не допускается).

## Запуск

```bash
./build/01_arithmetic
```

Цели: `01_arithmetic` (демо).

## Плохо → Хорошо

**Плохо** — ожидать дробный результат от деления двух `int`:

```cpp
double avg = 17 / 5;   // 3.0! деление выполнено в int, потом расширено
```

**Хорошо** — заставить деление быть вещественным:

```cpp
double avg = 17 / 5.0;                  // 3.4
double avg2 = static_cast<double>(17) / 5;  // 3.4
```

**Плохо** — делить без проверки делителя:

```cpp
int q = a / b;   // если b == 0 — неопределённое поведение, краш
```

**Хорошо** — проверить делитель и вернуть `std::optional`:

```cpp
if (auto q = arith::safe_divide(a, b); q) { /* ... */ }
```

> **Почему:** деление целого на ноль — это UB (а не исключение). Компилятор не
> обязан вас предупреждать, поэтому проверку нужно делать самому.
