# 02. Побитовые операторы

**Пункт плана:** 2 — побитовые операторы (`& | ^ ~ << >>`).

## Что показывает пример

* Все шесть побитовых операций с визуализацией через `std::bitset`.
* Битовые флаги: установка `|`, проверка `&`, сброс `&= ~`, переключение `^=`.
* Сдвиг как быстрое умножение/деление на степень двойки.
* Ловушку приоритета: `&` ниже, чем `==`.

## Запуск

```bash
./build/02_bitwise
```

## Плохо → Хорошо

**Плохо** — побитовые операции над знаковыми типами:

```cpp
int x = -1;
std::cout << (x >> 1);   // зависит от реализации/знакового бита
int mask = ~0;           // значение зависит от платформы
```

**Хорошо** — использовать беззнаковые типы для битовых манипуляций:

```cpp
unsigned int x = 0xFFu;
std::cout << (x >> 1);   // предсказуемый логический сдвиг
```

**Плохо** — забыть про приоритет `&` относительно `==`:

```cpp
if (flags & MASK == 0) { ... }   // это flags & (MASK == 0) — ошибка!
```

**Хорошо** — скобки вокруг побитовой операции:

```cpp
if ((flags & MASK) != 0) { ... }
```

> **Почему:** в таблице приоритетов `==` (10) выше, чем `&` (11). Без скобок
> выражение разбирается не так, как вы ожидаете, и `-Wall` это подсветит.
