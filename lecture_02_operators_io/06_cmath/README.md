# 06. Математические функции `<cmath>`

**Пункт плана:** 6 — математические функции `<cmath>`.

## Что показывает пример

* Базовые функции: `abs`, `sqrt`, `pow`, `ceil`, `floor`, `round`.
* Тригонометрию и логарифмы; константы `std::numbers::pi`/`e` (C++20).
* `std::hypot` — устойчивый расчёт гипотенузы.
* Почему `double` нельзя сравнивать через `==` и как делать правильно.

## Плохо → Хорошо

**Плохо** — нестандартная константа `M_PI` (нет в стандарте, требует костылей):

```cpp
double a = M_PI / 2;   // M_PI не гарантирован стандартом C++
```

**Хорошо** — `std::numbers::pi` из `<numbers>` (C++20):

```cpp
#include <numbers>
double a = std::numbers::pi / 2;
```

**Плохо** — сравнивать вещественные числа на точное равенство:

```cpp
if (0.1 + 0.2 == 0.3) { ... }   // false! двоичное представление неточно
```

**Хорошо** — сравнивать с допуском:

```cpp
if (mathx::almost_equal(0.1 + 0.2, 0.3)) { ... }
```

**Плохо** — считать гипотенузу «в лоб»:

```cpp
double h = std::sqrt(x*x + y*y);   // x*x может переполниться/потерять точность
```

**Хорошо** — `std::hypot`:

```cpp
double h = std::hypot(x, y);
```

> **Почему:** числа с плавающей точкой хранятся в двоичном виде, и десятичные
> дроби вроде 0.1 непредставимы точно. Сравнение через допуск (epsilon) — норма.
